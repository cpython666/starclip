# 数据与隐私边界

实施依据：`src-tauri/src/` 下的 `store.rs`、`privacy.rs`、`ai_access.rs`、`ai_transport.rs`、`capture.rs`、`images.rs`、`storage.rs`、`desktop.rs` 及 `src/api.ts`。面向用户的完整说明见 [产品范围](../../../../docs/product.md)、[星尘整理](../../../../docs/cleanup.md)；变更时同步这些说明。

## 采集与默认值

- 新安装为空、暂停记录、网格布局；`maxHistory = 0`、`retentionDays = 0` 表示不限条数与天数，窗口置顶和星伴默认关闭。升级保留已有暂停状态、布局、主题、上限与快捷键，不以新默认覆盖旧偏好。
- 2026-10-27 按用户要求修改：开启/恢复采集后首次轮询读取当前剪贴内容（通常约 700 ms 内），仍按原有去重、隐私和保留规则处理；首次安装默认暂停。`CaptureState` 不再跳过初始基线，读失败可重试、空内容不录入、自复制仍抑制。macOS/Windows 使用变更序号，其他平台内容比较；无效图片消费当前序号。见 `capture.rs` 四个固定数据测试，未读取真实剪贴板验收。
- 关闭主窗只隐藏，进程和已开启的记录继续；退出才结束，没有开机自启。复制放回系统剪贴板，不注入键盘或自动粘贴。
- 浏览器是原创样例的内存演示，不监听、不持久保存、不执行桌面定时清理，也不伪装真实目录操作、手写渲染或原生浮窗。

## 图片与保留规则

- 系统图片像素优先，按像素 SHA-256 去重；PNG 原图与最长边 320 px 的等比缩略图保存在 SQLite，列表只传元数据，可见后取图。Finder 文件路径不保证可读为图片。
- 单图限 1,600 万像素、任一边 16,000 px、PNG 20 MiB；系统解码发生在限额检查前，不能据此承诺进程内存峰值。
- 自动容量/时间清理只处理未星标、未永久保留且未分组的普通历史；按 `updatedAt` 计时，重复捕获会续期。不限条数和不限天数必须同时设置才停止这两种淘汰，不等于任意规模性能已验证。
- 启动、保存普通偏好、新增记录会应用自动规则；有限保留时长开启时，约每 60 秒检查，暂停记录也不暂停维护。主题补丁、教程标记和星伴保存不触发清理。
- 手动星尘整理以 AND 组合条件，始终保护星标与永久保留，默认排除分组。永久保留也禁止单条删除，必须先解除。
- 既有 `clear_history`（清空历史）命令只保护星标与永久保留，分组不是该命令的保护条件；不能将它与自动清理或星尘整理的筛选规则混用。
- 预览不写入；确认只处理该令牌的候选。候选变化/令牌失效整批拒绝，新记录不加入旧预览。内容字节不等于物理释放空间；删除提交后整理数据库失败应报告「已删除 + 整理警告」，不能宣称回滚。

## 产品分享

- `share.rs` 与 `product-share-catalog.json` 只解析固定文案 / 产品图 ID；原生端不接受任意剪贴正文、文件路径或远程 URL。复制和保存不查询历史，不修改统计、偏好或成长。图片来自打包资产，无需截图当前工作台，也不上传内容。
- 产品图复制与历史复制共用写入 helper，只在系统写入成功后调用 `CaptureState::copied` 抑制自身采集；失败不更新该标记。测试使用模拟写入函数，不读取真实系统剪贴板。
- 原生 PNG 上限 3 MiB / 200 万像素，校验固定路径、文件字节数和尺寸；当前三张图合计 248,512 字节（2026-10-26 定位改版）。桌面保存返回实际写入路径或取消，不走有创作奖励的导出命令。剪贴板接收方可能重新编码图片，内置压缩体积不代表接收文件大小。
- 分享遵守数据冻结；保存先检查状态，释放锁后打开系统对话框，确认后重新获得写入守卫。浏览器在不支持或拒绝剪贴板权限时明确报错并提供保存；不会借分享读取现有剪贴板来备份 / 还原。

## 隐私、规则与 AI 读取

实现与使用边界见 [隐私与规则](../../../../docs/privacy-ai.md)、[AI 接入](../../../../docs/ai-access.md)。原始设计保留在 `docs/open-data-ai-plan.md`，不以其中待定方案替代当前实现。

- 手动隐私与规则保护原因独立于普通标签，任一存在就保持隐私；移除标签、停用规则、重复采集、代码编辑或导入不能自动解除。只有本机主动复核可清理旧原因，仍命中当前规则则继续保护。列表 / 详情默认折叠隐私，清理预览标题固定为「隐私记录」，候选和原始数据不变。
- `add_protected`、`add_image`、`save_code`、标题更新与 `import` 均在同一写事务扫描后提交，重复内容也重扫并合并保护。规则损坏导致相关写入整体回滚；规则 revision 变化后旧扫描不可供 AI 读取。历史扫描预览不写入，确认前记录或规则变化使令牌失效；完整扫描事务不支持断点续扫。
- 检测使用 BIP39 英语 / 简中词表和 12 / 15 / 18 / 21 / 24 词校验；分隔词序列可嵌入文字，正文和标题独立检查。词表符合但校验失败的合法长度连续序列标为疑似。另检测 PEM 私钥、已列明凭据前缀、密码 / API key / Authorization 字段与 URL 用户信息 / 敏感参数。不是任意钱包格式或秘密的完整识别保证；词表与 MIT 来源在 `src-tauri/resources/bip39/README.md`。
- 正文扫描限 256 KiB、标题 200 字、URL 64 个；超限、URL 解析不完整及图片无 OCR 均不能成为 AI 可读记录。内置检测不提供关闭开关。浏览器演示不等同于 Rust 的完整敏感检测。
- `url` 标准解析器规范化主机；内置微信公众号 / LINUX DO / X / 哔哩哔哩按各自主机 / 子域边界匹配，短链独立分类且不联网展开。外层 URL 的路径 / query / fragment 内嵌 URL 不会误成为来源；仿冒后缀 / 用户信息不会冒充真实主机。自定义规则限 100 条，只支持本地关键词或精确域名加标签 / 标隐私，不执行任意正则或脚本。
- AI 默认关闭且只在当前主应用会话有效。每连接最多 500 条固定记录、单次 50 项、最长 7 天；读取 / 搜索 / 数量 / 标签 / 来源枚举共用 Rust 授权过滤，只搜索获准字段。图片、旧扫描、私密与未授权记录不可读，未知和无权 ID 使用同一错误。`get_state` 是主窗全量接口，不作 AI 出口。
- 星伴控制是独立 `allowPetControl` 权限，默认 false；可以只授权星伴、不选记录、不做历史扫描，仍无历史查询权限。`pet_signal` / `pet_clear` 复用同一回环 broker、CLI、MCP，短句最多120字符、1–60秒、每连接成功发送间隔至少500ms。只控制已开启星伴，动作沿用成长解锁，不加XP或改偏好；状态和短句仅内存，撤销 / 关闭 / 隐藏 / 到期清理。窗口事件加revision与启动快照，动画不回放，accepted不代表用户看见。见 `ai_access.rs`、`StarPetDesktop.vue`、[接口说明](../../../../docs/ai-access.md)。
- 固定授权同时绑定记录 ID 与 32 字节随机 `record_identity`。重复采集 / 合并保持身份；删除后 ID 复用、全新导入会得到新身份；身份不出现在 UI 数据或 JSON 备份中。完整 SQLite 快照保留身份，但会话连接不会跨重启保存。分类、分组和标签变化不能扩大授权集合。
- CLI / MCP 通过同一程序的模式参数连接回环临时端口，不直接读 SQLite；主应用从存储冻结到响应写出保持一致锁序。凭证与最多 200 条审计均仅在内存，审计不含查询、正文、标题、URL 或令牌；撤销、到期、关闭接入 / 主程序后后续读取拒绝。已传给外部 AI 的内容不能撤回；本机明文不能阻挡拥有同账户文件 / 屏幕权限的程序。

## 备份与目录迁移不同

| 操作 | 已实现范围与约束 |
| --- | --- |
| JSON 备份 | 统一 v3：片段、分组、图片原图、手动标签、隐私保护及规则；包含私密记录。不含外观 / 成长等其它偏好、手写组件、数据目录或 AI 连接 |
| JSON 导入 | 接受 v1 / v2 / v3，完整验证后事务合并，不覆盖普通设置、不立即清理；星标 / 永久与隐私保护只提升。v3 还原 `manualTags`，自动标签 / 来源 / 扫描版本按本机活动规则重算；后续维护仍遵循保留设置 |
| 迁移到新目录 | 复制一致的 SQLite 快照（含 WAL 内容），连同已保存偏好、手写配置及目录内受管渲染器；不覆盖目标、保留旧目录；目录外渲染器不复制 |
| 使用已有目录 | 校验后切换到目标数据，不合并当前记录；旧目录保留 |
| 完整恢复点（0.2.0） | SQLite 一致快照、全部已保存偏好与成长、手写配置和受管 renderer；附清单 / SHA-256，默认目录 `recovery/`，不自动删除 |
| 恢复完整数据 | 校验大小 / 摘要 / schema，先保存当前恢复点，再复制到新目录并切换；保留源目录与恢复点，重启前冻结；不合并新记录 |

- 单份 JSON 限 20 MiB、10,000 条片段、1,000 组及累计 2.56 亿图片像素；浏览器明确拒绝含图导入/导出，不丢图后声称备份成功。
- 导入规则以新 ID、停用状态追加到规则列表，用户可查看后自行启用，不覆盖活动规则；同策略重复导入去重，超过总 100 条整份拒绝。追加会递增 revision，已有未重扫记录暂不可供 AI 读取。
- Windows / macOS 桌面共用 `store.rs::export/import` 的 v3 导出与 v1 / v2 / v3 导入，与系统无关；跨系统记录互导是格式层面支持，尚未双机实测。普通历史 JSON 不含成长，成长另用 `starpet_growth.rs` / `starpet-growth.ts` 的 `starclip-starpet` v1 存档。记录格式兼容不等于完整环境兼容；路径、快捷键和手写可执行组件须单独处理，详见产品迁移边界。
- 2026-10-27 修复受管手写路径的跨平台表示：`select_app` / `selection_data` 共用 `portable_renderer_path` 写正斜杠，`renderer_path` 兼容旧 Windows 分隔符并先校验组件；拒绝上级目录、盘符/ADS与尾点空格等越界写法，保留原生外部绝对路径含义。两个固定样例覆盖编码边界、旧配置迁移及有正确摘要的旧恢复点读取/恢复；不代表跨系统可执行文件兼容。外部完整恢复点导入入口、双机验收仍待完成，`prepare_recovery` 只按 ID 从本机默认 `recovery/` 读取。
- 目录操作最终确认成功后冻结写入并请求重启；重启前不再写旧库，失败可重试。选择或取消不改位置，未保存草稿不会自动提交；失效定位不能静默创建空库掩盖问题。
- 数据及备份均为本机明文、未加密。位置以偏好中显示的实际目录为准，默认目录不保证是当前目录。受管占用不是整个目录占用，不含系统 WebView 缓存或无关文件。
- 不读正式数据验证功能。使用隔离应用标识与原创固定夹具；`artifacts/`、`.local/`、数据库、备份、日志已在 `.gitignore` 中排除，忽略规则不等于可发布这些内容。

## 数据结构与升级

- `store.rs::open_with_recovery` 先只读检查 `user_version`。当前结构版本为 2；高于支持版本时不打开写连接，不新建替代库。旧库在任何结构写入和启动清理前生成恢复点；新增 `clip_privacy`、既有内容扫描 / 随机身份、列 / 索引变更、版本和启动保留清理同事务提交，失败回滚并报告快照位置。
- 完整快照中受管文件禁止符号链接；清单上限 2 MiB、托管文件上限 10000。恢复前和复制后均验证摘要；损坏恢复点列表保留错误项，不影响其它点。恢复点不能直接选作可写数据目录。目录外 renderer 不复制，保留告警。
- 下载与安装分离：官方插件 `download()` 验证包签名和绑定版本后，已验证 bytes 仅存在本次会话并进入 `ready`；此时不安装 / 不冻结，可以稍后。确认安装只能取同版本 ready 包一次，重新检查 / 失败清缓存；退出后需重新下载。确认后生成 `before-update` 恢复点并备份旧应用，任何备份失败阻止安装；插件 `install()` 再次验签。安装冻结期间采集与所有写操作被后端拦截，保留原暂停偏好；正常退出也受安装阶段保护。`restart_app` 先释放目录锁再由 Tauri 拉起新进程，避免新进程与旧进程交接时自锁。
- 检查更新的失败提示由 `updater.rs::check_error_message` 按插件错误枚举生成中文并标识 GitHub，不拼接英文原始错误。当前插件2.14.0的 `ReleaseNotFound` 丢失具体非成功HTTP状态，不能推断为断网或404；提示链接访问失败或更新文件未发布的可能。见2026-10-27验证记录和固定错误分类测试。
- 2026-10-27 正式发布前公开端点实测：通过 Clash 可访问 GitHub Releases 列表（200），但正式 latest API 及应用配置的 latest.json 地址均 404；仅两个 alpha 预发布、无 latest.json 附件。当时持续检查失败有已确认的发布端原因，不能靠修改用户代理补齐；此结论只适用于该次检测时间，0.2.2 公开后的成功证据见下文。
