- 界面语言为「跟随系统 / 简体中文 / English」，默认跟随系统；与普通偏好一起保存，保存后立即切换并持久化，桌面端同步托盘菜单与主 / 星伴窗口标题。英文产品名为 Starclip、Starcode、Stardraw、Moonlight Note、StarPet / StarBud；用户内容、分组名和标签不自动翻译。宣传素材另有固定中英版本，默认跟随界面或在分享页手选，不改应用语言偏好。依据：`src/i18n/`、`App.vue`、`ProductShare.vue`、`store.rs::Settings.ui_language`、`desktop.rs::set_native_language`。
- 主界面主题与星码卡深空/晨光代码配色独立。主题切换即时独立保存；扩散动画支持被输入打断，减少动态效果或不支持 View Transition 时直接切换。
- 自定义强调色、纯色 / 双色渐变与 0–359° 方向、一张本地静态 PNG 贴纸已实现，入口为外观页。`appearance_v1` 独立保存；恢复配色不删贴纸，停用自定义图恢复内置贴纸。导入前后端有界校验、最长边缩至 512 并保留透明度，失败保留原值；完整快照包含，历史 JSON 排除。配色参考与限额见 [外观说明](../../../../docs/appearance.md)，原生重启恢复及验收边界见验证记录。
- 流星启动画面可跳过、关闭或重看，不在每次快捷键呼出时重播。教程只在新数据库首次使用自动出现，旧库升级不强制弹出；完成/跳过只写教程标记，不开启采集或触发清理。
- 2026-10-29 用户要求补齐三项启动选项，未发布源码已在使用习惯加入独立即时保存的登录自启动、启动收起主窗与菜单栏 / 托盘图标显隐，默认分别为关、关、开；不改记录暂停状态，也不提交普通偏好草稿。自启动以系统注册状态为准，只在主动启用时注册；系统登录项 / 后台运行权限仍可能限制启动。启动收起在下次启动生效，不创建主窗口，星伴遵循自己的已保存开关；快捷键或窗口偏好异常时显示主窗口以便修复。图标可立即隐藏，不强制开启另两项，通过快捷键、再次打开应用或 macOS Dock 恢复主窗；设置内提供退出并保护未保存草稿 / 任务。`showStartup` 仍只控制流星开屏动画。依据：`StartupSettings.vue`、`startup-api.ts`、`desktop.rs::{get_startup_preferences,set_startup_preferences,quit_starclip}`、`startup.rs`、`store.rs::WindowStartupPreferences`；全量自动检查与 macOS 隔离原生验收通过，Windows 本轮构建及真实注销重登尚待验证，具体范围见 `docs/verification.md`。
- 默认历史长期保留意味着 `maxHistory=0` 且 `retentionDays=0`，不批量设置单条 `keepForever`；用户仍可主动删除、整理或自行启用清理规则。既有已保存上限保持。依据：`store.rs::Settings` / `prune_history` 与既有不限历史测试。
- 2026-10-29 用户要求历史分页以减少内存：主列表改为 SQLite 每页 50 条、前端仅持有当前列表页，搜索和各项筛选仍覆盖全库，侧栏数量 / 标签 / 来源选项来自全库聚合。AI 授权列表独立分页与跨页选择，不被主列表当前页截断，不改变后端授权规则；分页不等于总运行内存已达到几十 MiB。依据：`store.rs::history_page`、`api.getState`、`HistoryPagination.vue`、`AiSettings.vue`。
- macOS Dock 点击走 `RunEvent::Reopen`，复用 `desktop.rs::show_window` 显示、取消最小化和聚焦主窗。不能用 `has_visible_windows=false` 限制，否则仅星伴可见时仍无法呼出主窗口；全局快捷键继续保留显示/隐藏切换语义。

## 偏好与弹窗：保留草稿，明确结果

- 当前未发布源码的八页为外观、星伴、使用习惯、规则与隐私、AI 与自动化、数据管理、分享、帮助；2026-10-29 将分享从帮助内折叠面板移为独立页，打开即显示素材。左侧文字导航、右侧独立滚动，标题和跨两列保存栏固定；窄预览保留文字并让内容控件换行，不用横向滚动分类。`aria-orientation=vertical`，键盘用上下 / Home / End。普通偏好跨页共用草稿，由「保存全部偏好」或 `⌘/Ctrl + S` 提交，保存后保持面板与位置。
- 主题、星伴开关/颜色/应用表情/大小、启动与后台运行、隐私标记与 AI 开关/撤销即时独立保存，不提交其他草稿、不触发保留清理。规则草稿独立保存、跨页保留；规则版本变化时，无未保存草稿才自动重读，有草稿则提示手动重读。星伴图库点选、巡游只是预览；跨窗口更新要合并补丁，不能覆盖刚保存的其他字段。启动开关只在后端成功后改变显示，失败可重新读取实际状态；读取和保存中通过 `busy` / `canRelease` 保护窗口释放。
- 2026-10-28 用户确认新版本提醒默认开启、可在设置关闭。未发布源码已提供独立即时保存的自动检查开关和单版本忽略：启动后尝试、最多每 24 小时自动联网一次，失败不弹提醒，更新提示只在主界面空闲时出现，不抢焦点、不自动下载安装；使用「稳定版」，预览通道未开放，不承诺 LTS 支持年限。依据：`UpdateNotice.vue`、`UpdateSettings.vue`、`desktop.rs::monitor`、`store.rs::UpdatePreferences`。
- 数据管理首次打开后保持挂载；目录操作忙碌或待重启时禁止换页。导入、整理、迁移是独立动作，不暗中保存其他偏好。
- 导出回执持续显示在按钮旁；桌面成功显示后端实际写入后的完整路径，取消与失败也明确反馈。浏览器只能确认下载请求与文件名，不能宣称知道下载目录。
- 星尘整理是独立同级 dialog，关闭后恢复原设置标签、草稿、滚动位置和入口焦点；不能销毁设置 DOM。整理期间拦截底层保存快捷键，通用提示应处于当前活动 dialog 内。具体修复及证据见 [2026-10-26 验证记录](../../../../docs/verification.md#导出反馈与清理窗口返回2026-10-26)。
- 帮助提供 GitHub 项目与新建 Issue 入口。桌面只允许固定 `repository` / `issues` 目标；不自动提交问题，不附带剪贴内容或日志。
- 2026-10-29 用户要求逐个优化后，未发布候选已实现独立「分享」页与中英素材：简短推荐 / 产品介绍两类各两语种，产品总览 / 数据自主 / 星伴陪伴 / 创作图片 / AI 接入与授权五主题各两语种，共 4 段文案、10 张 1080 × 1440 PNG。默认跟随界面，可手选中英，切换保留当前类型和主题；预览、复制、保存使用同语言版本。品牌区明确本地剪贴板用途，先讲复制历史与数据自主，再讲创作 / 可选星伴 / AI；固定原创样例不读取或截图个人历史。分享不授经验、不写统计、不保存偏好草稿，也不自动发布；成功、取消与失败在对应按钮附近反馈，不支持图片粘贴时提示保存。入口与语言逻辑见 `App.vue`、`ProductShare.vue`、`product-share-catalog.json`；素材 / 压缩及验证范围见 [分享说明](../../../../docs/product-share.md)。
- 本轮海报沿用原三主题结构并补齐创作与 AI 授权专题，去掉旧「桌面预览版」页脚，按对应版本的项目说明表述功能；仅为待发布候选。小体积宣传限定为「macOS 安装包参考约 7 MB」，随版本变化，不代表运行内存或字体下载后占用；23 个字体选项按需下载，不宣传全部离线或动画几十 MiB。AI 每次启动默认关闭，记录 / 字段 / 额度 / 到期由用户授权，官方接口排除隐私、待扫描与图片记录；星伴权限单独授予，已发给外部服务的内容不可撤回。启动选项在长文案中作为次要体验点。新图原生复制 / 保存、跨应用粘贴尚未验收，不能以目录检查或浏览器图像代替原生证据。

## 数据开放、隐私与 AI 接入

- 已实现的工作台布局为搜索下方折叠来源、多选来源 / 精确域名、普通标签和独立隐私状态筛选；来源之间 OR，其他维度 AND。微信公众号 / LINUX DO / X / 哔哩哔哩按后端 URL 元数据归类，短链标为未解析，不请求网页。普通标签区分手动与自动，编辑手动标签不把自动标签固化。入口：`App.vue`、`ClipPrivacy.vue`、`privacy.ts`。
- 隐私记录在网格、列表、流星栏和未展开详情中隐藏标题、正文及图片；用户可仅在本机展开。隐私标记与永久保留独立，复核解除后仍命中有效规则则继续保护。自动检测会误报 / 漏报，图片无 OCR，不能借折叠宣称加密。
- 2026-10-28 未发布修复：未 OCR 不是命中隐私规则，普通图片应直接显示；旧版该单一原因在读取时移除，不批量改写原数据库，手动保护和实际原因保留。图片标题仍会扫描，内部图片摘要不参与文本检测；所有图片继续禁止 AI 读取。详情在原文展开前展示「保护依据与命中规则」及不含敏感原文的解释，历史原因保留须明确说明。依据：`privacy.rs`、`store.rs`、`privacy.ts`、`App.vue`、`ClipPrivacy.vue`。
- 「规则与隐私」沿用采集与保留草稿，另有关键词 / 精确域名规则、普通标签 / 隐私动作、历史扫描数量预览和确认提交；不执行任意正则。内置检测始终开启，停用自定义规则不自动解除已有保护。导入规则用新 ID、停用状态追加，须手动启用；完整备份保留隐私数据。依据：`PrivacyRules.vue`、`store.rs`，详见 [隐私说明](../../../../docs/privacy-ai.md)。
- 「AI 与自动化」默认关闭，筛选后勾选明确记录 ID，预览字段 / 数量 / 时效后创建只读连接；隐私、未完成当前规则扫描和图片不可授权。连接不随标签、分组、新增或导入扩权；配置仅在创建或显式查看时显示，用户选择复制，不自动写其他客户端。撤销、关开关或重启使后续读取失效，已输出内容不能撤回。入口：`AiSettings.vue`、`ai-api.ts`、`ai_access.rs`，限额、CLI / MCP / Skill 和会话边界见 [接入说明](../../../../docs/ai-access.md)。
- 保护针对星笺官方接口；同账户文件或屏幕权限可能绕过，SQLite / 备份仍为本机明文。浏览器仅使用内存样例和基础规则，不创建真实 AI 连接或模拟完整敏感检测通过。原 [实施设计](../../../../docs/open-data-ai-plan.md) 保留后续方向：规则任意样例试跑、扫描暂停续扫、图片 OCR 等尚未实现；设计原型不能代替正式验收。

## 卡片与手写

- 代码默认进入星码卡，其他文字默认进入月光笺，切换保留正文；图片不进入文字工坊，手写模式不把正文另存为代码记录。
- 星码卡预览与 PNG 共用 Canvas；固定宽度软换行只影响排版，不修改正文、Markdown 或逻辑行号。超限提示用户调整，不静默裁切；具体尺寸上限查 `src/code-card.ts` 与产品范围。
- 2026-10-28 已确认并实现内置 CPU 手写渲染，无需额外手写应用。安装包不带 TTF，只带字体目录、静态预览小图与许可 / 提供说明；用户点击单款后才下载固定来源版本，核对大小 / SHA-256 后启用，失败不生效。下载字体位于 `current/fonts`，离线渲染，迁移与恢复包含、剪贴 JSON 排除。目录现有 23 款字体与字重，原手写应用 9 款全部接回并排在目录前部，纸张为暖白 / 纯白两种。当前 23 款均通过 macOS / Windows CI 的真实下载、大小 / SHA-256 核验与离线渲染；macOS 原 9 款已逐款原生 GUI 下载 / 导出，外部站酷快乐体已代表核对离线重启后的预览 / 导出。Windows 字体 GUI 尚未验收，细节见 [验证记录](../../../../docs/verification.md)；尚未正式发布。
- 手写自动预览须防止旧结果覆盖新输入，只有当前有效预览可导出；单页溢出会裁切、不自动分页，保持 10,000 字 / 800 万像素 / 10 MB PNG 上限。公开 0.2.2 的外部 CLI 历史验收不证明内置版已验证。

## 星伴

- 使用原创圆润 SVG，基础 32 种状态保持开放；25 种无手，挥手和持物等 7 种只有两颗小圆球。新增主动手势与手持装备按需显示圆球手，表情道具优先于冲突装备。概念图和提示词见 [设计说明](../../../../docs/starpet-design.md)，概念位图不进入安装包。
- 2026-10-29 用户要求日常展示正面心情：默认图库、桌面换心情与自动巡游共用 26 种正面 / 中性表情；`puzzled/sad/crying/angry/nervous/error` 六项在设置中主动展开并选择后才使用。保留既有明确保存的状态及 Agent 显式 error 调用；不得全局把这些稳定 ID 改写为 idle。巡游即使展开完整图库也只选日常池，临时动作结束恢复调用者已选心情。依据：`starpet.ts::everydayStarPetMoods`、`StarPetSettings.vue`、`StarPetDesktop.vue`。
- 默认关闭；支持预设色/HEX 与 70%–160% 大小。心情、颜色、大小独立保存并同步浮窗，换心情不重置颜色。
- 日常动作有停顿，观察、探头、平衡、舒展随心情选择；轻触与连续触碰有情境回应，不固定轮换心情、不每次必跳，临时反应不改写已选心情。开启成长后，主动摸摸可另行记录当天问好任务。只跟随本窗口角色区域内的指针，无 AI、联网或剪贴内容访问。
- 隐藏、卸载、停用动画或减少动态效果时停止动画循环。桌面本体左键按下直接发起原生拖动，不能等长按或移动阈值；键盘摸摸仍可用。精确拖动、透显等尚未完整验收，见 [星伴边界](../../../../docs/starpet.md)。
- `StarPetDesktop.vue` 互动菜单用 document 捕获阶段 pointerdown / focusin 处理外部操作，排除菜单与触发器；DOM blur 与 `starpet-api.ts::onStarPetWindowBlur` 的 `tauri://blur`（target Window/starpet）负责失焦收起，复用现有 event 权限。外部关闭不回焦，Escape / 显式关闭回焦入口；动作提交立即收起，异步结果不再控制菜单或焦点。卸载释放监听，迟到订阅立即释放。
- 养成默认关闭，独立于浮窗开关；20 级、三项每日任务、六成就、四槽十件装饰与六个主动动作均已实现。暂停保留进度及已有互动，离线不掉级、无断签惩罚；工作任务可用宠物互动替代。成长独立保存，不改其他偏好草稿；存档导入 / 重置须明确确认并防止覆盖确认期间的新进度。详细规则与来源见 [专题](growth-and-artwork.md)。
- 2026-10-27 未发布修复：设置任务 / 动作与浮窗互动共享后端校验、一次保存和 `starpet-interaction` 通知。只有已有且开启的浮窗播放，不自动唤起；同动作以 nonce 重播，不以成长 revision 是否增加判定。动画结束恢复已选心情，经验不重复发放。成功本地互动结束旧 Agent signal，以 signal revision 阻止迟到快照恢复；较新 Agent signal 可接管。事件发送失败独立提示，不将已保存成长误报失败。原生实测及自动回归范围见验证记录。
