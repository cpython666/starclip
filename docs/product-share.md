# 分享星笺

在「偏好设置 → 帮助 → 分享星笺」展开分享面板，可选择「简短推荐」或「产品介绍」并一键复制文案，也可预览产品图片、复制图片或保存 PNG。文案包含项目地址；软件不代替用户发布到社交平台。

三张介绍图均为 1080 × 1440，品牌区统一标明「本地剪贴板管理工具」，主标题直接使用「剪贴板」。使用原创示例与项目自己的星芽角色，不包含用户的剪贴记录。文案先说明复制历史、搜索与再次复制，再说明本地保存、JSON 导入导出和自选目录；星伴作为可选陪伴呈现。

| 图片 | 用途 | 压缩后大小 |
| --- | --- | ---: |
| 产品总览 | 直接介绍剪贴板历史、搜索、再次复制与收藏 | 79,739 字节 |
| 数据自主 | 本地保存、JSON 导入导出、自选目录与完整恢复点 | 72,060 字节 |
| 星伴陪伴 | 剪贴板工具中的可选星芽、成长与装扮 | 96,713 字节 |

三张合计 **248,512 字节，约 243 KiB**。预览、复制和保存使用同一份 PNG。桌面复制时会将 PNG 解码为系统图片剪贴板数据；接收应用可能重新编码，因此粘贴后文件大小不保证与内置 PNG 相同。需要保留这份压缩文件时使用「保存图片」。

宣传只描述已实现的能力：普通历史 JSON 包含记录、分组和图片，不含应用偏好；成长另有独立存档。数据与备份目前为本机明文。现有固定素材制作较早，尚未介绍后来已实现的 MCP、面向 AI 的 CLI / Skill 与本地隐私规则；当前能力与限制见 [AI 接入](ai-access.md)、[隐私规则](privacy-ai.md)。后续宣传应说明接入默认关闭、由用户选择记录与字段授权、隐私记录不向星笺官方 AI 接口开放，避免把本地保存描述成加密或绝对隔离。

## 2026-10-27 素材复核与待优化方向

- 已核实入口在「偏好设置 → 帮助」顶部，但「分享星笺」默认折叠；用户反馈未找到。待优化：在分类名称中明确「分享」，或增加直接打开素材面板的可见入口，减少寻找与展开步骤。本轮仅复核，没有改变入口。
- 三张现有图的大标题均直接表达剪贴板用途，可以保留这一主次关系；图上的细节文字较多，后续应让短文案更便于直接转发，每张图集中讲一个价值。当前 72,060–96,713 字节，无需为体积继续牺牲清晰度。
- 待补充「AI 接入与隐私授权」素材，展示主动选择资料、接口读取边界和可选星伴状态，不包含真实记录或连接凭据。MCP / CLI / Skill 是接入方式，不应暗示已内置 AI 模型或默认开放全部历史。
- 用户正在独立开展多语言支持。截至本次复核，分享面板标题 / 按钮调用 `t()`，正文仍直接显示目录中的 `text.content`，图片仍为三张中文 PNG。素材语言需单独制作 / 选择，并保证预览、复制、保存使用同一语言版本；界面翻译不等于宣传文案或图片已经翻译。本轮保留正在进行的代码改动，未制作或发布新的宣传素材。

## 操作反馈

- 文案可选中手动复制；一键复制成功后在按钮附近显示结果。
- 图片复制需要接收应用支持粘贴图片。浏览器不支持或拒绝剪贴板权限时会提示使用「保存图片」，不会显示复制成功。
- 桌面保存调用系统文件对话框，写入完成后显示实际路径；取消显示未写入。浏览器仅发起下载并显示文件名，不声称知道最终下载目录。
- 分享操作与偏好保存分开，不自动保存其他设置草稿。操作期间避免重复点击，并与更新、恢复等等待状态互斥。

## 素材与实现

文案、图片 ID、路径、尺寸和字节数统一保存在 `src/product-share-catalog.json`。静态图片位于 `public/share/`；前端入口为 `src/components/ProductShare.vue` 与 `src/product-share.ts`。

`scripts/share-posters.html` 是排版源，通过 Vite 渲染；使用原创固定界面和代码示意，星伴图直接渲染 `StarPet.vue`。它不是读取用户主窗口内容的截图工具。启动 `npm run dev` 后访问 `http://127.0.0.1:1420/scripts/share-posters.html?id=overview`，分别将 `id` 改为 `workflow`（数据自主）、`companion`。以 1080 × 1440、设备缩放 1 渲染，等待根元素的 `data-ready` 为 `true` 后截图。将三张图分别保存为 `artifacts/product-share-source/overview.png`、`workflow.png`、`companion.png`，检查排版后执行：

```sh
python3 scripts/compress-share-images.py artifacts/product-share-source
```

压缩脚本将素材转为 256 色索引 PNG、控制单张不超过 300 KiB，并同步目录中的实际字节数。Pillow 仅用于制作素材；软件运行和正常构建不需要 Python 或 Pillow。调色板压缩后需重新检查文字、渐变和角色边缘。

原生命令 `copy_product_share_text`、`copy_product_share_image`、`save_product_share_image` 只接收目录中的固定 ID，仅主窗口获准调用。图片通过 Tauri 资产解析器与前端共用同一份打包素材；开发模式需要先生成最新 `dist/`。Rust 校验 ID、静态路径、PNG 字节数与尺寸，并限制为 3 MiB / 200 万像素，配置或素材不符会明确报错。

分享不会读取剪贴板或历史、增加复制统计、修改偏好、发放星伴经验，也不上传数据。复制与既有历史复制共用写入函数；成功后登记本次内容以抑制应用自身采集，失败不伪造已复制状态。操作遵守更新及恢复后的数据冻结；保存对话框期间不持有数据锁，确认写入前再检查状态。

## 验证边界

纯 PNG / 目录校验、模拟剪贴写入后的采集抑制及生成后的窗口权限已通过检查；未使用真实剪贴板内容做测试。浏览器复制测试使用模拟接口，不能据此声称已在系统剪贴板或第三方接收应用中完成验收。原生保存、跨应用粘贴及平台构建的具体结果以 [验证记录](verification.md) 为准；未列出的实机场景仍待验证。
