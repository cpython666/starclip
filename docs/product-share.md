# 分享星笺

0.2.3 在「偏好设置 → 分享」提供独立素材页，打开即显示，无需先到帮助页展开。可选择「简短推荐」或「产品介绍」并一键复制文案，也可预览产品图片、复制图片或保存 PNG。文案包含项目地址；软件不代替用户发布到社交平台。新素材已随 0.2.3 正式发布；仍使用 0.2.2 的安装需升级后才能获得。

素材语言默认「跟随界面」，可手选「简体中文」或「English」，不改变应用语言偏好。每种语言有两类文案和五个图片主题，共 **4 段文案、10 张图片**；切换语言保留当前文案类型与图片主题，预览、复制和保存使用同一语言版本。英文正文与图片为独立编写的英文素材，不把界面按钮翻译当作正文翻译。

十张图均为 1080 × 1440，保留星空风格，并在品牌区明确本地剪贴板管理用途。产品总览先说明复制历史、搜索与再次复制，数据自主介绍本地保存和导入导出，星伴作为可选陪伴；新增创作图片与 AI 接入授权两个专题。全部使用原创固定样例和项目自己的星芽角色，不包含用户的剪贴记录、AI 连接凭据或主窗口截图。

## 文案范围与发布状态

- 这批内容已随 [0.2.3](https://github.com/cpython666/starclip/releases/tag/v0.2.3) 正式发布；已移除旧素材的「桌面预览版」页脚，改为按对应版本的项目说明核对功能与平台支持。三项启动偏好只放在产品介绍中作为次要体验，不取代剪贴板的核心用途。
- 「不到 8 MB」只指 macOS 安装包的体积，随版本与素材变化；不表示 Windows 包体积、运行内存、解包体积或下载字体后的占用。完整字体不随安装包提供，目录为 **23 个可选字体与字重，逐款按需下载**，下载后可本地生成月光笺；不承诺所有字体随包或动画星伴只占几十 MiB。
- 普通历史 JSON 包含记录、分组和图片，不含应用偏好；星伴成长另有独立存档。数据与备份为本机明文，不宣传为加密或绝对隔离。素材本身可离线使用，但更新检查、字体下载和可关闭的功能统计可能联网，不能把整个产品描述为完全离线。
- AI 接入每次启动默认关闭；MCP、CLI、Skill 是接入方式，星笺不内置 AI 模型。用户选择记录、字段、单次额度与有效期后授权；官方接口中的剪贴历史始终只读，隐私、待扫描及图片记录不可授权，新记录不自动加入旧连接。星伴动作与消息单独授权，可不开放任何记录。连接可撤销，重启需重新授权；已发给外部 AI 的内容无法撤回，其后续处理由相应客户端或服务决定。

当前能力与限制见 [产品范围](product.md)、[AI 接入](ai-access.md)、[隐私规则](privacy-ai.md)。

## 操作反馈

- 文案可选中手动复制；一键复制成功后在按钮附近显示结果。
- 图片复制需要接收应用支持粘贴图片。浏览器不支持或拒绝剪贴板权限时会提示使用「保存图片」，不会显示复制成功。
- 桌面保存调用系统文件对话框，写入完成后显示实际路径；取消显示未写入。浏览器仅发起下载并显示文件名，不声称知道最终下载目录。
- 分享操作与偏好保存分开，不自动保存其他设置草稿。操作期间避免重复点击，并与更新、恢复等等待状态互斥；忙碌时不允许切换素材语言或释放当前面板。

## 素材与实现

文案、图片 ID、`locale`、路径、尺寸和字节数统一保存在 `src/product-share-catalog.json`。`texts` / `images` 两个数组分别包含 `zh-CN` 和 `en-US`；标签与说明由界面翻译，正文、PNG 和下载文件名按素材语言选择。前端入口为 `App.vue` 的独立 `share` 标签页、`src/components/ProductShare.vue` 与 `src/product-share.ts`，静态图片位于 `public/share/`。

固定中文文本 ID 为 `short` / `detailed`，英文为 `short-en` / `detailed-en`。中文图片 ID 为 `overview` / `workflow` / `companion` / `creation` / `ai`，英文在相同主题后加 `-en`；路径为 `share/<id>.png`。切换语言按主题 ID 匹配，不会把当前创作图切回总览。

`scripts/share-posters.html` 是排版源，通过 Vite 渲染；使用原创固定界面和代码示意，星伴图直接渲染 `StarPet.vue`，创作图明确标为排版示意而非特定字体效果承诺。它不是读取用户主窗口内容的截图工具。启动 `npm run dev` 后访问 `http://127.0.0.1:1420/scripts/share-posters.html?id=overview`，将 `id` 替换为上述十个图片 ID。以 1080 × 1440、设备缩放 1 渲染，等待根元素的 `data-ready` 为 `true` 后截图。每张保存为 `artifacts/product-share-source/<id>.png`，检查排版后执行：

```sh
python3 scripts/compress-share-images.py artifacts/product-share-source
```

压缩脚本按目录处理十张素材，转为 256 色索引 PNG，控制单张不超过 300 KiB，并同步实际字节数。Pillow 仅用于制作素材；软件运行和正常构建不需要 Python 或 Pillow。调色板压缩后需重新检查文字、渐变和角色边缘。

原生命令 `copy_product_share_text`、`copy_product_share_image`、`save_product_share_image` 只接收固定素材 ID，仅主窗口获准调用。图片通过 Tauri 资产解析器与前端共用同一份打包素材；开发模式需要先生成最新 `dist/`。Rust 只解析固定目录中存在的安全 ID，校验静态路径、PNG 字节数与尺寸，并限制为 3 MiB / 200 万像素，配置或素材不符会明确报错；语言配对由目录与前端检查覆盖。

分享不会读取剪贴板或历史、增加复制统计、修改偏好、发放星伴经验，也不上传数据。复制与既有历史复制共用写入函数；成功后登记本次内容以抑制应用自身采集，失败不伪造已复制状态。操作遵守更新及恢复后的数据冻结；保存对话框期间不持有数据锁，确认写入前再检查状态。
