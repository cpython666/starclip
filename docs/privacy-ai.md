# 隐私规则、来源筛选与 AI 只读接入

星笺在本机保存、分类和检测内容。标签和网站来源用于整理；隐私状态独立于普通标签。AI 只能通过受限接口读取你明确授权的记录，不能访问完整工作台。

## 整理与保护

工作台可组合来源、普通标签和隐私筛选，不同维度按 AND 组合，同一来源维度的多个选项按 OR 组合。微信公众号、LINUX DO、X、哔哩哔哩提供来源名，其余链接可按完整域名筛选；一条文字中的多个链接可以有多个来源。短链单独注明未解析，不自动访问网页、跟随跳转或下载正文与图标。

域名来自标准 URL 解析：例如 `x.com.evil.example` 不属于 X，`https://example.test/?next=https://x.com` 的来源是外层网站。内置来源按各自主机 / 子域边界匹配；自定义域名规则为精确匹配，不包括子域。

记录详情可保存普通标签或手动标记「隐私 · 不向 AI 提供」。隐私记录的标题、正文和图片在列表中折叠，在本机详情主动展开查看。手动标记与规则原因分别保存，移除普通标签、重复采集、导入或停用规则不能自动解除保护。复核并尝试解除时重新扫描，仍命中有效规则就继续保护。

「偏好设置 → 规则与隐私」保留采集与历史保留设置，并提供关键词 / 精确域名规则，可自动加普通标签、标为隐私或两者同时执行。规则单独保存，不提交其他偏好。修改后先预览历史扫描影响，再确认应用；预览只显示数量。记录或规则在确认前变化时，旧预览失效，需要重新预览。当前历史扫描是完整事务，不支持中途暂停续扫。

## 自动检测范围

- 助记词：BIP-39 英语、简体中文词表，12 / 15 / 18 / 21 / 24 词与校验和；词表匹配但校验失败也作为疑似内容保护。不能因此判断钱包是否有效或存在资产，也不覆盖所有钱包格式。
- 私钥与凭据：PEM 私钥标记、已列明的凭据前缀、密码 / API key / Authorization 等字段、URL 用户信息和敏感参数。
- 自定义规则：本地关键词及精确域名；不执行任意正则或脚本。
- 扫描不完整：超出文本或链接扫描上限、链接解析不完整等情况不向 AI 开放。图片没有 OCR，始终排除 AI 读取。

检测会有漏报和误报，不能把“未命中”理解为安全保证。内置规则始终开启；敏感正文、匹配片段与完整链接不会写入 AI 调用日志。词表来源和许可证保留在 `src-tauri/resources/bip39/README.md`。

## 创建 AI 连接

1. 在「规则与隐私」完成已有文字记录的扫描。
2. 打开「AI 与自动化」，主动开启本机接入。默认关闭，重启后恢复关闭。
3. 筛选并勾选具体记录，确认标题 / 正文 / 标签 / 来源等允许字段、每次结果数和有效期。
4. 预览后创建连接，再把生成的 MCP 配置放入信任的 AI 客户端，或使用生成的 CLI 命令。Skill 文本可按客户端要求保存为 `SKILL.md`。

如果只想让 Agent 使用星伴，直接勾选独立的「星伴动作与消息」权限即可，不用扫描或选择历史记录。资料始终只读；星伴控制不能获取历史、增加经验或改变存档。两种权限可分别授予，具体状态、动作和限时短句参数见 [AI 与星伴接口](ai-access.md)。

每个连接最多选 500 条，每次最多 50 项，最长有效 168 小时，并且仅在当前主应用运行期间有效。授权绑定固定记录 ID 与内部随机身份；删除后新建的记录不能继承旧授权；之后新增记录、分组移动、自动加标签或导入都不会扩大集合。每次读取还会检查当前规则版本和隐私状态。规则变化后，未完成新扫描的旧授权记录暂时不可读。

连接凭证只在内存中保存，通过客户端环境变量传递。界面生成的配置包含短期凭证，不应放进 Git、公开截图或分享材料；不会自动修改其他软件配置。撤销连接、关闭总开关、连接到期或主程序退出后，后续读取失败；已交给外部 AI 的内容无法撤回。

## MCP、CLI 和 Skill

三种入口共用同一个 Rust 权限层。主应用持有数据库，本地桥接只绑定 `127.0.0.1` 的临时端口；CLI / MCP 不直接打开数据库。使用安装包内同一个可执行程序，在启动图形界面前识别 `ai` / `mcp` 参数，不需额外的 Node 或 Python 运行时。

| 工具 | 内容与限制 |
| --- | --- |
| `status` | 当前连接状态、字段、限额与到期时间；无全库数量 |
| `search` | 只搜索已授权字段与记录；摘要最多 300 字，数量在允许范围内 |
| `get` | 按 ID 获取获准记录；正文最多 8,000 字，截断会注明 |
| `list_sources` | 仅统计当前获准记录的来源主机，需授权来源字段 |
| `list_tags` | 仅统计当前获准记录的普通标签，需授权标签字段 |
| `pet_signal` / `pet_clear` | 独立星伴权限；在已开启星伴显示或收起本连接的临时状态、动作与短句 |

不存在、隐私和未授权 ID 使用相同错误；不开放图片、分页游标、资料写入、任意 SQL、任意路径、备份、实时剪贴板或执行代码。返回资料明确标为不可信用户内容，资料里的文字不能充当新的操作指令。接口不会自行调用云端 AI。

界面生成的路径和端口是准确入口。基本形式为 `starclip mcp --port PORT` 或 `starclip ai --port PORT search '{"query":"示例","limit":10}'`，凭证使用 `STARCLIP_AI_TOKEN` 环境变量；Windows 请使用生成的 PowerShell 入口并遵循其 JSON 参数引号规则。接入细节见 [AI 接入说明](ai-access.md)，使用约定见 [用户 Skill](ai-skill/SKILL.md)。MCP 实现声明支持 `2025-06-18` 协议版本。

本次运行最多保留 200 条调用记录，仅记连接名称、工具、时间、返回数量和结果，不记查询词、正文、标题、凭证或完整 URL。关闭主应用后不保留连接和调用记录。

## 备份与保护边界

SQLite 结构升级为 2，沿用升级前一致快照、事务迁移和未来版本拒绝。旧记录保留，在完成本地扫描前不能授予 AI。JSON 导出统一为 v3，包含记录、图片、分组、手动标签、隐私保护信息及规则；仍可导入旧 v1 / v2，新格式不能交给只支持旧格式的版本。

所有导入按本机活动规则重扫，不信任文件自报的扫描版本或分类。重复内容合并只增加隐私保护；自动标签与来源重新计算，手动标签保留。导入规则以新 ID、停用状态追加到本机规则列表，不覆盖活动规则，用户可在规则页查看后手动启用。规则总量上限 100，超限整份拒绝，不静默丢规则。

普通 JSON 不包含外观、成长、手写组件或数据位置等完整环境；完整恢复点与目录迁移包含 SQLite 中全部偏好。所有备份都包含隐私记录，仍是本机明文，导出不会悄悄漏掉私密数据。

**隐私保护限定于星笺官方接口。** 有同账户文件、屏幕或桌面操作权限的程序可能绕过接口；这不是加密保险库或系统级 AI 隔离。外部 AI 客户端拿到获准内容后是否联网，由该客户端决定。

源码与验证边界见 [产品范围](product.md) 和 [验证记录](verification.md)。浏览器只演示固定内存数据与基础分类，不创建真实 AI 连接，也不模拟完整敏感检测通过。
