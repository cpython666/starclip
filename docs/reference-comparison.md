# 参考体验与功能适配（2026-10-24）

## 实际查看的范围

- 从剪切助手官网下载并启动 macOS Apple 芯片版 0.0.8，查看「剪切板」「快捷键」「通用设置」页面。确认可见的横向 / 纵向布局、深浅主题、分组切换快捷键、按天到年保留历史的选项。检查结束后退出客户端并卸载安装镜像，没有登录、开启同步或授予辅助功能权限。
- 在代码小抄公开网页切换代码主题，代码区域从深色变为浅色；拖动卡片手柄后预览宽度改变。创建页可新增代码片段、展开标签和描述；切换片段后原创示例仍保留。没有登录或提交公开内容。
- 剪切助手快捷粘贴与指定内容快捷键仅确认设置入口可见，未实测跨应用粘贴；其云同步、图片捕获及长期保留效果未验证。网页公开界面可见不等于已验证服务端保存。

## 本轮适配

| 参考发现 | 原有星笺 | 本轮实现 |
| --- | --- | --- |
| 横向 / 纵向布局 | 网格与列表 | 「流星栏」横向卡片视图，复用搜索与复制操作 |
| 分组切换快捷键 | 全局呼出、数字复制、方向键浏览 | 窗口内 `⌘/Ctrl + Shift + ←/→` 循环切换分类与分组，编辑时不抢按键 |
| 按时间保留历史 | 按数量上限淘汰 | 默认不限天数，可选 1 / 7 / 30 / 90 / 180 / 365 天；按 `updatedAt` 最近更新计算，仅处理未星标且未分组的普通历史 |
| 代码区独立主题 | 外框背景可调，代码区固定深色 | 星码卡增加「深空 · 深色」「晨光 · 浅色」代码配色，外层背景独立选择 |
| 拖动调整卡片宽度 | 根据最长行自动定宽 | 默认自适应；可用滑杆设定 320–960 px 代码窗宽度，渲染时软换行，保留正文与原始行号 |
| 横向取用的配套需求 | 普通桌面窗口 | 可选窗口置顶，默认关闭；浏览器演示不模拟系统置顶 |

窗口置顶是根据取用场景补充的设计，不作为本次参考客户端已实测的功能。实现与验证结果以 [验证记录](verification.md) 为准。

## 本地实现的规则

- 流星栏沿用现有搜索、分类、分组和复制操作；方向键选择、Enter 复制仍只把内容放回剪贴板，不自动切回其他应用粘贴。分类切换快捷键只在窗口内工作，输入文字、输入法组合和弹窗内不触发。
- 升级不改既有暂停状态、布局、主题、历史上限与呼出键；新增保留时长默认不限、窗口置顶默认关闭。流星栏需要主动选择。
- 自动清理按 `updatedAt` 计算，重新捕获相同内容刷新起点；星标和分组记录同时受到容量及时间规则保护。桌面版在启动、保存偏好、新增记录时应用规则，有限保留时长开启后约每 60 秒检查，暂停记录时也检查。不限天数仍受容量上限约束。
- 备份导入完整验证后按内容合并，不覆盖当前设置，不在导入动作内裁减条目；之后仍受正常清理触发点约束。手动「清理历史」另行确认，只保留星标，会删除未星标分组记录。
- 浏览器仍为不持久化的内存演示；不监听剪贴板，不模拟系统置顶，没有桌面定时维护。公开网页界面的观察也不代表验证过其账号、服务端保存或后台行为。
- 星码卡的宽度指代码窗，不含外层留白。软换行不改原文、保存内容或 Markdown，不为续行新增行号。保持 100 个逻辑行、每行 120 个 Unicode 码点的限制（Tab 按两个空格计），中文、组合 emoji 与重音字符按完整字符排版。2 倍输出实际位图每边不超过 16,384 px，总计不超过 2,400 万像素；无法容纳时明确提示调整。

## 继续保留的边界

- 用户数据、本地备份与参考软件安装包不加入源码仓库。没有复制第三方源代码、商标或视觉素材。
- 不因对照参考软件而自动开启采集、改变现有用户偏好、部署同步服务或申请系统辅助功能权限。
- 标签 / 独立备注、多片段集合、图片与文件剪贴板、跨应用自动粘贴、云同步和公开分享链接仍留待后续实现；现有标题和分组已可用于本地检索整理。
