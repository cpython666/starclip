# 星笺 0.1 产品范围

## 方向

星笺 Starclip 将剪贴历史、代码收藏和卡片制作连接成：复制 → 搜索 → 星标 / 分组 → 星绘坊 → 本地分享文件。星码集用于收藏与管理代码片段；星绘坊统一星码卡（代码分享图片）与月光笺（手写纸笺）的制作入口，月光笺模式接入本机独立星笺 Rust 应用。已有记录可通过「带入星绘坊」进入制作界面。

视觉采用深空蓝、星尘金和青色点缀。深色界面优先，内容保持高对比度，装饰不遮挡文本。交互支持键盘、表单标签、清晰焦点和原生对话框。

## 默认行为与历史保留

升级保留既有暂停状态、主题、布局、历史上限及呼出键。新增字段默认「不限保留天数」与「窗口不置顶」，不自动启用流星栏或采集。首次运行仍为空历史、暂停记录、网格布局。

保留时长可选不限、1、7、30、90、180、365 天，以 `updatedAt` 最近更新时间计算，不以创建时间计算；重新捕获相同内容会刷新保留起点。容量和时长清理都只处理未星标且未分组的普通历史，不限天数仍受容量约束。

桌面版在启动、保存偏好、新增记录时应用规则；有限保留时长开启后，运行期间约每 60 秒检查，暂停记录不暂停这一维护检查。备份先完整验证、按内容合并，导入动作不立即运行清理；此后仍会在上述触发点按当前规则清理。自动清理不能撤回，可先导出备份。手动「清理历史」另有确认，只保护星标，不保护未星标分组。

浏览器为不持久化的内存演示，不监听剪贴板、不实施系统置顶，也没有桌面的定时清理。浏览器中的清理交互仅用于演示新增记录、保存偏好时的规则。

## 星码卡排版边界

独立代码配色为「深空 · 深色」和「晨光 · 浅色」，不随外层背景或主界面主题改变。固定代码窗宽度 320–960 px，不含外层留白；自适应仍是默认。软换行只改变绘图，完整保留代码、Markdown 和保存内容；行号对应原始逻辑行，续行不另编号，空行保留。

最多 100 个逻辑行、每行 120 个 Unicode 码点，Tab 转成两个空格后计数。中文、组合 emoji 和重音字符按完整字符软换行；单个完整字符超过宽度时提示增宽。预览与 PNG 使用同一 Canvas，按 2 倍尺寸生成，实际位图每边最多 16,384 px、总计最多 2,400 万像素。软换行导致过高或过大时拒绝生成并提示调整，不静默裁切代码。
