# 星笺 0.1 产品范围

## 方向

星笺 Starclip 将剪贴历史、代码收藏和卡片制作连接成：复制 → 搜索 → 星标 / 分组 → 星绘坊 → 本地分享文件。星码集用于收藏与管理代码片段；星绘坊统一星码卡（代码分享图片）与月光笺（手写纸笺）的制作入口，月光笺模式接入本机独立星笺 Rust 应用。已有记录可通过「带入星绘坊」进入制作界面。

视觉提供星夜、月白、青苔、暮樱四套主题，并可跟随系统；以星空和流星作为启动画面的视觉元素。内容保持高对比度，装饰不遮挡文本。交互支持键盘、表单标签、清晰焦点和原生对话框。

## 默认行为与历史保留

新安装默认「不限条数」和「不限保留天数」（`maxHistory = 0`、`retentionDays = 0`）、窗口置顶关闭；首次运行为空历史、暂停记录、网格布局，流星启动画面默认开启。升级保留既有暂停状态、主题、布局、历史上限及呼出键，不自动启用流星栏或采集。旧版已保存的 500 条等上限不会被改写，需自行同时选择不限条数与不限天数，才会停止这两项自动淘汰规则；这不代表任意数据规模的性能已经验证。

保留时长可选不限、1、7、30、90、180、365 天，以 `updatedAt` 最近更新时间计算，不以创建时间计算；重新捕获相同内容会刷新保留起点。容量和时长清理都只处理未星标、未永久保留且未分组的普通历史。永久保留独立于星标和分组，侧栏分类显示全库永久保留记录，卡片显示盾牌，编辑时可勾选；单条删除前需先解除永久保留。

桌面版在启动、保存偏好、新增记录时应用规则；有限保留时长开启后，运行期间约每 60 秒检查，暂停记录不暂停这一维护检查。备份先完整验证、按内容合并，导入动作不立即运行清理；此后仍会在上述触发点按当前规则清理。旧备份缺少 `keepForever` 时按 `false` 解析，合并只提升星标与永久保留保护，不降级已有保护。自动清理不能撤回，可先导出备份。

工具栏与设置中的「星尘整理」以 AND 组合大小、更新时间、类型及分组条件，始终跳过星标与永久保留，默认排除分组。预览不删除，确认后只处理该预览的候选；候选变化或令牌失效会整批拒绝。可同时整理数据库，也可在无匹配时仅整理文件；内容字节不能视为预计物理释放量，详见 [星尘整理说明](cleanup.md)。

浏览器为不持久化的内存演示，不监听剪贴板、不实施系统置顶，也没有桌面的定时清理或真实目录管理。「星尘整理」可操作演示记录，新增记录和保存偏好也会演示自动规则；没有实际数据库文件，物理空间释放为 0。

## 启动画面与外观

流星启动画面在启动时短暂显示，约 1.4 秒后自动进入工作台；支持「跳过」和 Escape，不在每次快捷键呼出时重复。偏好设置可关闭或重看。系统要求减少动态效果时，隐藏流星动画并将展示缩短至约 0.45 秒。

主题为星夜（深色）、月白（浅色）、青苔（浅绿）、暮樱（暖粉）；跟随系统时只在星夜与月白之间切换。主题选择覆盖主界面、偏好与星绘坊外观，与导出星码卡的深空 / 晨光代码配色相互独立。文档中的主题和启动页截图使用合成样例，不含真实剪贴数据。

17 处下拉菜单与 2 处颜色选择器改用统一品牌控件，保留原选项的字符串、数字和 `null` 值语义；勾选框、滑块、数字输入及折叠箭头也随主题显示。下拉支持方向键导航、输入文字定位，以及 Tab / Escape 关闭；切换设置标签页会收起菜单。颜色面板支持预设色与完整 HEX，只有合法值才能通过 Enter 或按钮提交，非法草稿不写入当前颜色。浏览器已核对四套主题与上述交互；本机 macOS 隔离原生验收还确认主题键盘切换、Escape 只关闭菜单、下缘菜单向上展开、保留天数草稿取消，以及手写字体 / 纸张 / 墨色选择后成功生成原创预览，见 [验证记录](verification.md)。

文件和目录选择仍使用系统提供的访问流程，包括导入导出、渲染器选择和数据迁移；这次统一的是应用内控件，没有实现自造文件管理器。界面示例：[主题菜单](custom-theme-menu.png)、[颜色面板](custom-color-panel.png)。

贴纸默认跟随当前主题：星夜 → 星月漫游、月白 → 云朵小狗、青苔 → 花园来信、暮樱 → 奶油猫咪；跟随系统时按最终的星夜 / 月白主题匹配。四套均为原创轻量 SVG，可独立选择或关闭，不接收点击、不遮挡操作，也没有新增运行依赖。

## 偏好分区与新手教程

偏好分为「外观」（主题、贴纸）、「星伴」（星芽开关、表情预览、巡游）、「使用习惯」（启动动画、布局、快捷键、置顶）、「记录与隐私」（采集、条数、天数）、「数据管理」（数据目录、迁移、导入导出、星尘整理）与「帮助」（教程、常用快捷键）六页。标题和底部操作栏固定，内容区单独滚动；普通偏好跨页保留同一份草稿，由「保存全部偏好」或 `⌘/Ctrl + S` 统一保存。星伴开关和应用表情单独立即保存，不走普通设置保存、不清理历史，也不保存其他页草稿。

标签使用单一键盘焦点入口，支持方向键及 Home / End 切换，换页复位内容滚动。数据管理首次打开后保持挂载，隐藏其他页时不丢失目录操作状态；数据操作忙碌或待重启时禁止换页。导入、清理和目录操作独立执行，不会暗中保存其他页的草稿。

「初见星笺」包含拾起灵感、留下重要的、做成卡片、掌管数据四步。仅真正新建数据库首次使用时，在启动画面结束后自动展示；已有数据库即使历史为空，升级也不自动弹出。帮助可随时重看，返回保留设置草稿。跳过或完成只写 `preferences` 中独立的 `onboarding_v1` 标记，不调用偏好保存，不改记录、采集开关或清理配置，也不触发清理。教程与弹窗期间不触发记录复制或分类切换快捷键。

## 星伴与桌面窗口边界

星芽为独立设计的原创星星角色：日常陪伴 8 种、小小心情 12 种、一起做事 12 种，共 32 种状态。设置页支持点选、分类与巡游预览；桌面默认关闭，开启或「用这个表情陪我」才保存 `starpet_v1`。当前是手动表情与轻互动，不联网、不接入 AI，也不读取剪贴内容。

SVG 星角支持柔性变形，目光、脸部和身体以分层弹簧运动转头；眨眼有不等间隔的单眨 / 双眨，切换表情带闭眼过渡。设置页主星可以点击，桌面每次摸摸也会触发反应：蓄力、跳起、落地压扁、回弹，并出现 6 颗柔和星光。同一状态连续点击可重播，衔接时保留姿态与速度。

动画仅在组件已挂载、允许动画、系统未开启减少动态效果且页面可见时运行；其他情况下取消动画帧循环、保持静态。表情图库以静态缩略图为主，本轮没有新增运行依赖。

桌面端配置为 230×260 的独立透明 Tauri 窗口，提供拖动把手、摸摸、换心情、打开主窗口及收起入口，未引入大型运行依赖。位置不持久化，不承诺逐像素穿透或跨全屏；多屏、Windows 和长期资源占用未验收。浏览器只预览表情，不创建原生浮窗。

已通过 17 项 Node 测试、29 项 Rust 测试（另 1 项忽略）、前端生产构建及正式 Apple Silicon app / DMG 打包；额外 1 项运行时 ACL 检查确认星伴只允许 4 项专用命令，拒绝 27 项主窗口命令。浏览器已核对 32 种表情、12 项工作分类、巡游和实际 SVG 变形，检查时为 1 个动画主预览与 32 个静态缩略图。原生已核实启动、重启后保留既有关闭状态与表情、开启、摸摸 / 连续触碰星光弹跳、换心情；前版收起星伴后主程序仍保留也已补测。

正式应用已替换启动，设置中的可点击 SVG 入口已操作；升级前后历史、分组、偏好逻辑摘要以及手写配置 / 渲染器哈希一致，未改正式开关。当前 app 为 8.63 MiB、DMG 为 3.76 MiB。原生透明截图被工具扁平为 RGB 白底，无法确认实际桌面透显；拖动工具未报错，但缺少绝对位置读回，不算精确位置验收。开启状态重启、托盘、原生关闭事件及上述多屏等边界仍未完成验证，详情及精确包体积见 [星伴文档](starpet.md)。

## 数据位置与迁移边界

偏好「数据管理」中的「数据位置」显示实际使用目录、默认目录、位置配置文件路径及受管数据占用，并可打开当前目录。占用口径为数据库及 WAL / SHM 日志、月光笺配置和目录内受管渲染器，排除位置配置、系统 WebView 缓存及无关文件。

「选择迁移目标」先选择父目录，再展示将新建的专用子目录。选择与取消不会改动数据位置；确认后以一致数据库快照复制历史、星标、分组及已保存偏好，同时迁移月光笺配置与目录内受管渲染器，不覆盖已有目录，保留旧目录。目录外的渲染器不会复制，会提示重新选择。

「使用已有数据目录」经过路径确认与校验后，改用该目录的历史、分组和偏好，**不与当前记录合并**，当前目录仍保留。两种操作成功后都会冻结写入并请求重启，重启后使用选定目录；自动重启失败时提供重试，期间不继续写入旧数据库。操作前需先保存其他偏好，未保存的设置草稿不会自动保存。

原生迁移、重启、采用已有目录及失效路径恢复已在 macOS 隔离验收应用中完成验证，仅使用原创测试记录，具体证据与范围见 [验证记录](verification.md)。浏览器不会读取本机路径、选择目录或伪装迁移成功；Windows 原生流程尚未实机验证。

数据及 JSON 备份均为明文、未加密；星笺没有云端上传。JSON 备份仅含片段与分组，不包含偏好、手写配置 / 渲染器、数据目录设置，单份上限为 20 MiB、10,000 条片段和 1,000 个分组，因此不能替代完整目录迁移；选择不限历史条数不会提高备份上限。

## 星码卡排版边界

独立代码配色为「深空 · 深色」和「晨光 · 浅色」，不随外层背景或主界面主题改变。固定代码窗宽度 320–960 px，不含外层留白；自适应仍是默认。软换行只改变绘图，完整保留代码、Markdown 和保存内容；行号对应原始逻辑行，续行不另编号，空行保留。

最多 100 个逻辑行、每行 120 个 Unicode 码点，Tab 转成两个空格后计数。中文、组合 emoji 和重音字符按完整字符软换行；单个完整字符超过宽度时提示增宽。预览与 PNG 使用同一 Canvas，按 2 倍尺寸生成，实际位图每边最多 16,384 px、总计最多 2,400 万像素。软换行导致过高或过大时拒绝生成并提示调整，不静默裁切代码。

## 月光笺预览与导出

连接本机手写渲染器且正文有效时，首次打开月光笺自动生成预览。正文、字体、纸张、字号、墨色或留白变化后，短暂停顿便在本机重新渲染；生成期间仍可编辑，较早请求的过期结果不会覆盖新内容。只有预览与当前正文和设置一致时才能导出 PNG，失败后可重试。

单页超出纸张区域的文字会裁切，不自动分页，导出前需检查预览。仍限 10,000 字、800 万像素及 10 MB PNG。浏览器不模拟手写渲染，明确提示使用桌面版；字体与渲染器仍由独立星笺 Rust 组件提供，未捆绑进安装包。自动预览已通过本机 macOS 隔离原生验收，见 [验证记录](verification.md)。
