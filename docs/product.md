# 星笺 0.1 产品范围

## 方向

星笺 Starclip 将剪贴历史、代码收藏和卡片制作连接成：复制 → 搜索 → 星标 / 分组 → 星绘坊 → 本地分享文件。星码集用于收藏与管理代码片段；星绘坊统一星码卡（代码分享图片）与月光笺（手写纸笺）的制作入口，月光笺模式接入本机独立星笺 Rust 应用。已有记录可通过「带入星绘坊」进入制作界面。

视觉采用深空蓝、星尘金和青色点缀。深色界面优先，内容保持高对比度，装饰不遮挡文本。交互支持键盘、表单标签、清晰焦点和原生对话框。

## 首版边界

| 能力 | 状态 |
| --- | --- |
| 文本监听、去重、SQLite、暂停、历史容量 | 已实现，待每个平台实际桌面验证 |
| 搜索、分组、星标、复制、深浅色、布局 | 已实现 |
| 星码集：标题 / 语言 / 代码编辑、行号、语法高亮、JSON 格式化 | 已实现 |
| 星码集 Markdown 与星码卡 PNG 导出 | 已实现；PNG 限 100 行、每行 120 字符 |
| 星码卡：背景、横纵留白、阴影、窗头、行号、水印与透明度 | 已实现；代码预览与 PNG 共用 Canvas |
| 星绘坊：星码卡 / 月光笺双模式，已有片段直接带入 | 已实现；切换保留正文，月光笺不写入代码记录 |
| 月光笺：手写字体、纸张、字号、墨色、留白、PNG 预览 / 导出 | 已实现本机 CLI 接入；需另有星笺 Rust 版，单页不自动分页 |
| 手写渲染器随安装包分发、两产品仓库合并 | 未实施；当前复用本机独立应用 |
| 全局呼出、托盘、快捷复制 | 已实现；快捷键冲突会提示 |
| 备份导出和事务导入 | 已实现 |
| 图片 / 文件 / 富文本 / 自动回到原应用粘贴 | 后续 |
| 标签、备注、多片段代码集合 | 后续 |
| 云同步、分享链接、账号与加密分享 | 后续；没有部署服务 |
| 代码执行、AI 分析、OCR | 后续；不执行剪贴内容 |
