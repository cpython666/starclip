# 自定义主题色、渐变与本地贴纸

入口：「偏好设置 → 外观」。五套基础主题与跟随系统保持可用；自定义配色在基础主题上叠加，切换基础主题会重新适配文字与按钮的明暗。

## 配色与方向

- **主题强调色：** 颜色面板或六位 HEX，用于按钮、选中项与重点文字；自动调整明度保持可读，不承诺所有控件逐像素采用原始色值。勾选「强调色跟随基础主题」可单独恢复默认。
- **窗口背景：** 跟随基础主题、自选纯色、双色渐变。渐变可分别设置起点与终点、交换颜色，并从五种配色预设开始编辑。
- **渐变方向：** 0–359° 整数，支持数字、滑块和八方向快捷按钮。采用 CSS 角度语义：0° 向上，90° 向右，180° 向下，270° 向左；交换颜色与改变角度是独立操作。
- **阅读底色：** 配色预览与窗口顶部装饰带显示完整配色，主工作区叠加基础主题底色，卡片和设置面板保留清晰的阅读背景。主应用配色不改变星码卡导出的独立配色。
- **恢复主题配色：** 恢复基础主题的强调色与背景，不删除导入的贴纸，也不修改其它偏好。

「柔粉奶油」使用 `#d9a7c7 → #fffcdc`、90°，配色参考用户指定的 [uiGradients · Broken Hearts](https://uigradients.com/#BrokenHearts)。色值与默认向右方向核对自其 [官方颜色目录](https://github.com/ghosh/uiGradients/blob/main/gradients.json)、[应用默认方向](https://github.com/ghosh/uiGradients/blob/main/src/App.vue) 和 [显示组件](https://github.com/ghosh/uiGradients/blob/main/src/components/Display.vue)。第三方名称只作为参考说明，不作为星笺主题名称；没有嵌入远程页面或下载整套站点资源。

## 导入贴纸

选择自己的静态 PNG，可保留透明背景。当前保存一张自定义贴纸，支持替换、启用 / 停用与确认移除；原始文件不变。启用时覆盖侧栏与页眉的内置装饰，停用或移除后恢复当前内置贴纸选择。装饰不能接收鼠标事件或遮挡操作，不改变星伴形象。

导入限制为 **5 MiB、最长边 2048、最多 400 万像素**。前端检查格式与尺寸，Rust 再校验编码、PNG 结构和动画标记，并有界解码；缩至最长边 512 像素、保留 alpha、重新编码去除元数据。最终 PNG 不超过 512 KiB；超限或损坏会明确报错并保留原贴纸。暂不支持 JPEG、WebP、SVG、GIF 或动画 PNG。

文件选择使用本机文件输入；不读取剪贴板、不上传图片、不保存外部文件路径。文件名只用于显示，不作为读写路径。贴纸仅存入用户自己的外观偏好，不自动进入产品分享图或安装包。

## 保存与备份

自定义外观使用 SQLite 偏好 `appearance_v1`，与普通设置草稿分开。操作完成后立即保存并生效，无需点击底部保存；失败保留上次确认值，读取损坏数据时显示错误与重试，不静默覆盖。

原有内置贴纸选择仍由「保存全部偏好」提交。自定义外观不会提交其它设置、启动历史清理、增加复制统计或发放成长奖励；与迁移、恢复、更新等操作互锁，并遵守后端数据冻结。四个自定义命令仅主窗获准调用。

桌面版重启读取已保存的外观。完整恢复点与数据目录迁移包含偏好及贴纸；普通剪贴历史 JSON 不包含这些设置。浏览器仅为内存演示，刷新后还原，不伪装持久保存。
