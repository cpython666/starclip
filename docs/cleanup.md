# 星尘整理与历史保留

从工具栏或「偏好设置」打开星尘整理，按条件预览、核对，再确认删除。预览和取消都不会执行清理。原生永久保留、筛选、确认删除与数据库整理已通过本机 macOS 隔离应用 `com.starclip.cleanup-verify` 验收，详见 [验证记录](verification.md)。

整理是独立窗口。从设置进入，关闭后仍回到原标签和滚动位置，其他偏好草稿不会丢失或自动保存；从主界面进入则返回主界面。导出备份的保存路径、取消或错误会持续显示在数据管理页的按钮下方。

本次使用 8 条原创记录与 1 个分组，全程暂停记录，未接触正式历史。确认清理 1 条后剩余 7 条，数据库从 512 KiB 缩减至 416 KiB，实际释放 98,304 字节，退出后的只读 SQL 检查与界面一致。本次文件选择器未完成导入界面流程；测试应用退出后，将已存 JSON 夹具填入空的隔离数据库，保留了恢复快照与 JSON，不能视为原生导入验收通过。

## 筛选与确认

所有条件以 **AND** 组合，记录必须同时满足：

| 条件 | 计算方式 |
| --- | --- |
| 内容大小 | 文字为正文与标题的 UTF-8 字节合计；图片为原图 PNG 字节加标题，不计内部标识与缩略图。严格大于输入阈值；可选 KiB / MiB，0 表示不限 |
| 最近更新早于 | 按 `updatedAt` 判断早于指定天数，不按创建时间；0 表示不限 |
| 类型 | 全部、文本、链接、代码、色彩或图片 |
| 包含已分组记录 | 默认关闭；开启后仍跳过星标和永久保留记录 |

「大内容 · > 32 KiB」「30 天前」「全部未保护」是快捷预设，会重置其他条件，并默认排除分组记录。重新捕获相同内容会更新 `updatedAt`，因此可能不再符合旧时间范围。

预览展示全库条数、去重后的保护条数、精确匹配条数与内容字节合计；保护条数指星标或永久保留记录，不把仅因分组而排除的记录计入其中。明细最多列出前 100 条标题，**确认会删除全部匹配项，不只是可见明细**。

勾选删除确认后才能执行，删除无法撤回。修改筛选条件会使预览与确认失效；执行时若预览令牌失效，或任何候选已被删除、修改内容 / 标题 / 更新时间 / 分组 / 保护状态，会拒绝整批操作，需重新预览。预览后新增的记录不属于本批候选，不会被这次清理删除。

## 内容大小与磁盘空间

预览的「当前数据库文件」是 SQLite 主文件与 WAL 日志的当前大小；「已有可复用空间」来自数据库空闲页。**内容字节不是预计磁盘释放量**：图片按原图 PNG 加标题统计，文字按正文加标题统计；缩略图、索引、页面布局与日志都会影响文件大小。

「同时整理数据库文件」默认开启。没有匹配记录时，仍可确认仅整理数据库；取消勾选则只删除记录，数据库可复用空间不一定立即归还文件系统。结果展示执行前后文件大小及实际缩减，不保证与内容字节相等；若最终大小无法读取，会明确提示释放量暂无法测量。

若删除已经提交、随后数据库整理失败，结果会保留已删除条数并显示警告，不能把它理解为删除失败或已回滚。可重新预览，并在无匹配时再次仅整理数据库。SQLite 整理需要额外临时磁盘空间，可能达到原数据库大小的两倍，见 [SQLite VACUUM 文档](https://www.sqlite.org/lang_vacuum.html)。

浏览器仅操作内存中的演示记录，没有实际数据库文件，物理空间释放始终为 0；刷新后不保留演示修改。

## 哪些记录会保留

| 记录状态 | 容量 / 时间自动清理 | 星尘整理 |
| --- | --- | --- |
| 星标或永久保留 | 始终跳过 | 始终跳过 |
| 已分组，未星标且未永久保留 | 始终跳过 | 默认跳过，仅显式勾选时纳入 |
| 其他普通历史 | 按已保存规则淘汰 | 符合全部筛选条件才纳入 |

以上规则同样适用于图片。「永久保留」分类汇总全库此类记录，卡片用盾牌标记，编辑时可勾选。永久保留也保护单条删除，需先解除保护再删除；它不会因取消星标或移出分组而自动解除。

新安装默认 `maxHistory = 0`、`retentionDays = 0`，即不限条数与天数。升级保留原有条数上限；要关闭这两项自动淘汰，必须同时选择「不限条数」与「不限保留天数」。不限仅表示不设自动淘汰阈值，不代表已验证任意规模的存储或界面性能。

桌面版在启动、保存偏好、新增记录时应用自动规则；有限保留天数开启后，约每 60 秒检查，暂停记录时也检查。星尘整理是单独确认的手动操作。

## 备份与迁移

JSON 备份包含片段、分组与图片原图，包括星标与永久保留状态；含图采用 v2，纯文本采用 v1。单份限 20 MiB、10,000 条片段、1,000 个分组和累计 2.56 亿图片像素。浏览器演示明确拒绝含图备份的导入 / 导出，不会跳过图片。旧备份没有 `keepForever` 时按 `false` 处理，按内容合并时只提升保护，不取消当前已有保护。导入先完整验证，导入本身不按容量或天数裁减，但后续正常维护仍会应用当前规则。

超出单份备份上限时，可使用完整目录迁移。它包含数据库中的图片，另含已保存偏好、月光笺配置与目录内受管渲染器：复制一致数据库快照，不覆盖已有目录，保留旧目录，重启后生效。「使用已有目录」只切换、不合并。数据和 JSON 均为本机明文、未加密，没有云端上传；完整范围见 [数据位置与迁移边界](product.md#数据位置与迁移边界)。
