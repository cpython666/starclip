## 素材使用与后续建议

1. 默认随包提供可追溯的原创角色与装饰；对每项新增资产记录作者 / 贡献者、来源、制作过程、许可范围及修改记录。AI 辅助创作也保留提示词与人工修改记录，不因使用 AI 自动视为无权利风险。
2. 采用第三方开放素材前逐项核对原始来源、许可证版本、署名、修改及源码 / 二进制再分发条件；声称“免费”或可下载并不足够。
3. 当前已提供用户本地静态 PNG 导入，保存在个人外观偏好，不附送第三方角色包、不上传、不建立公共素材库；限额见 [外观说明](appearance.md)。本地导入不改变图片原有权利，导出 / 分享仍需按各自权利范围使用。
4. 若正式引入知名角色，需由有权授权的一方明确覆盖软件内置、源码公开、二进制分发、修改及允许用户导出的用途。不能把第三方素材整体改标为项目 MIT；许可无法满足开源再分发需求时，不纳入默认开源资产。

本轮没有替换既有界面贴纸、加入第三方图片或修改许可证；新增养成装饰为本地内联 SVG。实现范围见 [星伴养成系统](starpet-growth.md)。
