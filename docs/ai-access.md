# 星笺 AI 接入与星伴控制

本轮已实现本地界面授权、主应用受控读取、同一发行程序的 CLI / MCP 模式，以及[对外 Skill](ai-skill/SKILL.md)。初版为**当前应用会话内连接**：每次启动默认关闭；关闭总开关会撤销全部连接；退出、重启、到期或单独撤销后，旧配置不能继续读取。不会自动改写其他 AI 客户端的设置。

在「AI 与自动化」开启本机接入，分别选择记录读取和「星伴动作与消息」权限，预览后确认创建。只用星伴可以不选择任何记录，也不需要扫描历史；原有记录连接不会自动获得星伴权限。读取记录仍需明确选择记录、字段、单次额度与有效期。配置中 `command` 使用当前星笺程序的实际路径，`args` 包含模式与本机临时端口，环境变量 `STARCLIP_AI_TOKEN` 是随机短期凭证。配置应保存到 AI 客户端私有设置，不能放入 Git、分享材料或日志。每次重新创建需替换旧配置。

MCP 模式是 `starclip mcp --port PORT`；CLI 模式是 `starclip ai --port PORT TOOL [JSON]`。两种模式都从环境变量取得凭证，在 Tauri 和桌面插件启动前分流，不会打开第二个应用窗口。macOS 应用包内和 Windows 安装目录中的主程序本身就包含这两个模式，无需另安装脚本或 sidecar；Windows 手工 CLI 使用父控制台，MCP 保留客户端继承的标准输入输出管道。实际路径以界面配置为准。源码可通过 `cargo build --manifest-path src-tauri/Cargo.toml` 构建同一二进制。

| 工具 | 输入 | 输出范围 |
| --- | --- | --- |
| `status` | `{}` | 当前连接能力、到期时间、额度和字段，不含数据目录、全库数量 |
| `search` | 可选 `query`、`limit` | 只搜索获准标题 / 正文；先过滤再计算总数；摘要最多 300 字符 |
| `get` | 整数 `id` | 当前可见记录；正文最多 8000 字符，`truncated` 标识截断 |
| `list_sources` | `{}` | 仅可见资料的主机名与计数，需允许来源字段 |
| `list_tags` | `{}` | 仅可见资料的普通标签与计数，需允许标签字段 |
| `pet_signal` | 可选 `status`、`action`、`message`、`durationSeconds` | 临时星伴状态 / 动作 / 短句，需单独星伴授权 |
| `pet_clear` | `{}` | 只收起这个连接当前发出的星伴提示，不能清除其他连接的提示 |

## 将 Agent 状态显示在星伴上

先由用户在「星伴」设置显示星伴，再创建允许「星伴动作与消息」的连接。接口不会自行打开星伴、抢焦点或改变用户保存的心情。`status` 返回这个连接实际允许的工具和 `allowPetControl`；`clipboardReadOnly` 始终为 true。只授权星伴的连接不能搜索或读取历史。

MCP 直接调用 `pet_signal`。CLI 在界面生成命令的路径、端口、凭证基础上使用下面的参数（macOS / POSIX shell 示例）：

```sh
starclip ai --port PORT pet_signal '{"status":"thinking","message":"正在分析需求","durationSeconds":15}'
starclip ai --port PORT pet_signal '{"status":"success","action":"greet","message":"任务完成了"}'
starclip ai --port PORT pet_clear '{}'
```

- `status`：`idle`、`thinking`、`working`、`waiting`、`success`、`error`，对应空闲、思考、工作、等待、完成、出错。
- `action`：`greet`、`highfive`、`stretch`、`twirl`、`heart`、`celebrate`，尊重当前成长等级解锁。调用不加经验、不更改装扮或存档。
- `message`：最多 120 个 Unicode 字符，拒绝控制字符；仅作为纯文本展示，并标注授权连接名。
- `durationSeconds`：1–60 的整数，默认 10 秒，且不超过连接剩余有效期。状态、动作、非空短句至少提供一个。

每个连接两次成功发送至少间隔 500 ms。多个 Agent 的最新有效提示覆盖上一条；撤销所属连接、关闭总开关、隐藏星伴或到期会清除提示。用户也能收起气泡，或通过摸摸星伴 / 切换心情恢复自己的交互。信号仅存在本次运行的内存中，不进入剪贴历史、备份或调用日志正文。需要长时间显示工作状态时，在必要状态变化或到期前续期，避免高频轮询。

`accepted:true` 表示主应用已接受并发出窗口事件，不等于已经完成动画或用户已经看见；窗口加载时通过快照恢复尚未过期的文字与状态，不重播旧动作。当前没有动画完成回调、任务队列、HTTP 服务或远程控制。

每连接最多 500 条记录、单次最多 50 项、有效期最多 7 天；同时最多 20 个连接。记录输出始终包含 ID、类型和不可信资料标识，其余标题 / 正文 / 标签 / 来源按连接字段授权。搜索不以未获准字段为条件，禁止借查询结果数探测隐藏正文。初版不提供分页；`cursor`、`offset` 和其他未知参数拒绝，不能用 `human`、`trusted` 等参数绕过权限。

图片不向 AI 提供。有旧历史时先在「规则与隐私」完成可扫描文本的当前规则检测；图片不会阻碍安全文本授权。之后每次读取重新检查当前规则版本、隐私状态和持久记录身份。连接绑定授权当时的 ID 与随机记录身份，新增、导入、重建记录或 SQLite ID 复用不会自动得到旧授权；分组 / 标签的变化也不会增加记录集合。不存在与无权查看返回同一错误。

主应用使用仅绑定 `127.0.0.1` 的临时端口与随机 256 位凭证。桥接是有界、单工作线程的私有换行 JSON 协议，MCP 对外使用 stdio；不是 HTTP 或公网服务。不保存凭证文件。CLI / MCP 不打开数据库，不读取系统剪贴板。每个读取响应持有与本地修改一致的存储 / 数据 / 授权锁直到写出；数据迁移、恢复或更新冻结时拒绝读取。标记隐私、撤销和响应写出有明确先后顺序，已发送给客户端的数据无法撤回。

审计仅在当前进程内保留最近 200 次已识别连接调用的名称、动作、时间、返回数和结果，可清空；不记录搜索词、正文、标题、URL、星伴短句、令牌或错误细节。没有资源订阅、图片读取、资料写入、任意 SQL、任意路径、备份、权限修改或执行代码工具。所有工具输出均为不可信用户资料，Skill 只说明用法，权限由主应用实施。

保护范围为星笺官方接口。同账户程序若已获得文件、屏幕或桌面操作权限，可能绕过接口；同账户恶意程序也可影响本地桥接可用性。SQLite 与完整备份仍为本机明文。把允许的片段交给外部 AI 后，其后续处理由该客户端或服务决定。

验证边界：本轮 macOS 上已通过真实回环 broker 的隐私 / 撤销 / 冻结 / 并发保护测试、删除后复用 ID 的身份隔离测试，以及实际主程序子进程的 CLI / MCP stdin/stdout 交互。Windows 已按同二进制与继承管道实现，原生实测需在 Windows 完成；平台构建不等同于客户端接入实测。

协议实现采用 [MCP 2025-06-18 stdio 传输](https://modelcontextprotocol.io/specification/2025-06-18/basic/transports)、[初始化生命周期](https://modelcontextprotocol.io/specification/2025-06-18/basic/lifecycle)与[工具规范](https://modelcontextprotocol.io/specification/2025-06-18/server/tools)。
