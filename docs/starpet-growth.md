# 星伴养成系统

状态：**第一版已实现**。更新日期：2026-10-26。包含 1–20 级、三项日常任务、六项成就、四个装扮槽与十件原创装饰、六个主动动作，以及独立成长存档。接球、吹泡泡、专注计时、透明 PNG 贴纸导出等仍是后续方向，尚未实现。实现范围不等于所有平台已验收，具体证据见 [验证记录](verification.md)。

## 体验与入口

入口在「偏好设置 → 星伴 → 星芽的成长手记」，包含「成长 / 装扮 / 成就」三个标签。主预览保留原有表情、颜色与大小；动作区旁另有同步装扮的小预览，点击动作时不用滚回顶部。桌面浮窗通过「和星芽互动」打开动作菜单；本体仍在按下时立即发起原生拖动，授奖不阻塞拖动。

2026-10-27 未发布修复补齐设置与浮窗的动作联动：设置中的任务 / 动作按钮校验成功后，已开启的桌面星芽播放同一动作与回应，结束恢复已选心情。重复点击仍会重播，经验仍遵循每天每项一次；星伴关闭时不会自动开启。本地互动会结束旧 Agent 提示，后来的新 Agent 信号仍可显示。验证范围见 [验证记录](verification.md)，公开 0.2.2 尚不包含此修复。

互动菜单在点击外部、窗口失焦、键盘焦点移出或使用其他星伴按钮时收起，不抢回当前焦点；菜单内部普通点击保持展开，再点入口可收起。选择已解锁动作立即收起，异步结果不会影响之后重新打开的菜单。Escape 与关闭按钮收起后回焦入口；隐藏和卸载也会清理菜单及事件监听。系统失焦使用限定到星伴窗口的 Tauri 事件和 DOM blur，未增加全局鼠标监听或窗口权限；实测边界见 [验证记录](verification.md)。

成长记录默认关闭，与桌面浮窗开关独立。开启后记住一起做过的小事；暂停后保留经验、成就和装扮，仍可使用已开放的互动。关闭浮窗也能在设置内互动，不要求开启剪贴采集。

成长只有一个长期经验值，等级由经验计算。没有饥饿、掉级、断签惩罚或多套货币；没有抽卡、交易、排行榜。现有 32 种表情、颜色和大小保持开放。新增的比心、庆祝等是临时动作，不是新增的基础表情 ID，结束后恢复原心情。

## 日常任务

| 任务 | 完成条件 | 经验 |
| --- | --- | --- |
| 来打个招呼 | 当天第一次主动摸摸或问好 | 10，每天一次 |
| 陪我玩一会 | 完成击掌，或已解锁的转圈、比心、庆祝动作 | 15，每天一次 |
| 留下一点小美好 | 一起伸懒腰，或在桌面版成功保存代码、导出卡片 | 20，每天一次；任一途径完成即算 |

每天合计最多 **45 XP**。任务奖励自动记录，物品自动放入收藏，穿戴由用户主动选择。成就只发徽章或物品，不叠加经验。前三个基础动作从 Lv.1 即可使用，因此完全暂停采集也能完成三条任务。

同一次问好、击掌或伸懒腰只完成对应任务。重复互动仍有回应，不重复发经验；当天没做完不会补作业。表情墙点选、巡游、装扮预览、加载存档都不记奖。桌面代码保存与卡片导出仅在成功后尝试记奖，取消和失败不授奖；成长写入失败不会把已经成功的保存 / 导出变成失败。

不按复制次数、记录条数、删除数量、开启采集或挂机时长发奖励，不反向扫描已有历史。浏览器可以用内存数据演示宠物互动、等级和装扮，但不影响正式成长，刷新后重置；浏览器中的代码保存 / 卡片下载不触发正式工作奖励。

本机日期用于日常额度。日期前进只开放新一天的任务，不补发离线奖励；日期倒退不刷新已用额度、不扣经验，界面会提示经验暂不增加。未做在线校时或反作弊服务，不保证抵抗手动修改系统时间。

## 等级与奖励

升级所需经验为 `40 + 10 × (当前等级 − 1)`；1 级起点为 0 XP，达到 L 级的累计门槛为 `40 × (L − 1) + 5 × (L − 1) × (L − 2)`。当前等级上限为 20，累计经验上限为 10,000,000。满级后仍可积累经验，不会产生尚未制作的奖励。

| 等级 | 累计经验 | 已实现的奖励 |
| --- | ---: | --- |
| Lv.1 | 0 | 问好、击掌、伸懒腰开放；开启成长后首次问好获得「初见小星徽」 |
| Lv.2 | 40 | 月牙圆框眼镜 |
| Lv.3 | 90 | 转个圈动作 |
| Lv.5 | 220 | 夜航小披风、星光同行成就 |
| Lv.8 | 490 | 小星球玩具，可穿戴于手持槽；接球玩法尚未实现 |
| Lv.10 | 720 | 慢慢长大成就与星环点缀 |
| Lv.12 | 990 | 偷偷比心动作、比心小贴纸 |
| Lv.16 | 1650 | 流星围巾 |
| Lv.20 | 2470 | 星图披风、星光庆祝动作 |

第一天完成三条任务可得到 45 XP，升到 Lv.2。按每天完成三项、每日 45 XP 推算，Lv.20 需 55 个有任务奖励的日子；这是数值推算，不是长期实测结论。页面显示当前等级与累计经验，不把跨窗口同时增加的经验归因于某次点击。

## 动作与装扮

主动动作共六个：问个好、击个掌、一起伸懒腰、转个圈、偷偷比心、星光庆祝。动作在当前角色上短暂播放，保留原心情；开启系统减少动态效果时采用静态回应。日常观察、探头、平衡、舒展、眨眼和情境摸摸继续沿用原实现。

装扮分为 **背部、面部、手持、点缀** 四槽，每槽一件，可单独卸下；披风、眼镜、玩具与点缀可同时穿戴。十件物品如下：

| 位置 | 物品 |
| --- | --- |
| 背部 | 夜航小披风、流星围巾、星图披风 |
| 面部 | 月牙圆框眼镜 |
| 手持 | 小星球玩具 |
| 点缀 | 初见小星徽、比心小贴纸、小月牙胸针、小玩伴贴纸、星环点缀 |

披风位于身体后层，眼镜跟随脸部，手持玩具使用两颗小圆球握住。读书、写字、捧杯等既有表情优先使用自己的道具，冲突时暂时收起装备的手持玩具，换回不冲突的表情后恢复。基础 32 表情的无手 / 圆球手约定保留，新增主动手势和持物装备按需显示圆球手。

装饰与动作的 SVG 为本项目新增的内联绘制，见 `src/components/StarPet.vue`；目录、名称、解锁条件见 `src/starpet-growth-catalog.json`。没有加入第三方角色图片或新增运行依赖。这里的小贴纸是星芽身上的装饰，不能导出透明 PNG，也不会替换主界面既有四套贴纸。素材权利边界见 [素材核对](artwork-rights.md)。

## 六项成就

| 成就 | 条件 | 奖励 |
| --- | --- | --- |
| 初次相遇 | 开启成长后完成第一次问好 | 初见小星徽 |
| 今天也见面了 | 累计互动七天，无需连续 | 小月牙胸针 |
| 好会穿搭 | 开启成长后首次穿戴已获得的装饰 | 穿搭纪念徽章，在成就页显示 |
| 小小玩伴 | 累计五天完成玩耍任务 | 小玩伴贴纸 |
| 星光同行 | 达到 Lv.5 | 旅伴纪念徽章，在成就页显示 |
| 慢慢长大 | 达到 Lv.10 | 星环点缀 |

每项成就只授予一次，不要求连续打卡。成长暂停时可调整已有装备，但不新增成就。后续的更多互动成就、专注成就及套装收藏仍未实现。

## 存档、权限与同步

- `preferences.starpet_growth_v1` 独立保存版本、开关、总经验、计奖日期、当日任务、必要累计计数、已获成就 / 物品、装备与同步修订号。不保存剪贴正文、标题、图片、来源应用或逐次行为日志；原有 `starpet_v1` 和普通设置不会被成长写入覆盖，也不会触发历史清理。
- Rust 统一处理授奖、每天限额、解锁与装备校验，事务保存后向主窗口和浮窗广播 `starpet-growth-changed`。前端提交动作或装备选择，不能传任意 `+XP`；使用单调修订号避免较旧响应覆盖新状态。
- 星伴浮窗在原有四个自定义命令外，仅新增读取成长、启停成长、宠物互动、装备选择四个命令，共八个。导出、导入和重置成长三个命令仅授权主窗口；星伴仍不能查询历史、图片或剪贴内容，也不能直接申报代码保存 / 导出奖励。
- 成长存档导出使用独立 JSON，格式为 `starclip-starpet` v1，大小上限 64 KiB。桌面成功后显示实际路径，取消明确反馈；浏览器只能报告下载请求与文件名。
- 导入先验证并展示等级、经验、装饰数量、成长开关，用户确认后整体替换，不累加。校验版本、日期、数值、物品 ID 与装备所属位置；不支持的或不合法的内容直接拒绝。确认期间如成长修订号变化，会要求重新预览，避免覆盖新进度。
- 重置也须明确确认，只清空成长与装扮、暂停成长，不清空剪贴历史或改变表情 / 颜色 / 大小。导入、重置失败时保留原成长记录。
- 当前剪贴历史 JSON 备份不含偏好，因此不含成长；需要单独导出成长存档。完整目录迁移包含 SQLite，但新增成长记录随迁移的原生流程仍需单独验收。

实现入口：`src/starpet-growth-catalog.json` 为前后端共用目录，`src/starpet-growth.ts` 提供类型、进度计算、存档校验与浏览器演示，`src/starpet-growth-api.ts` 连接命令 / 事件，`StarPetGrowth.vue` 管理设置页交互；Rust `starpet_growth.rs` 处理成长规则，`store.rs` 事务存储，`desktop.rs` 负责命令、业务成功后的记奖与窗口广播。
