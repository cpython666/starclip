# 星芽：原创星星桌宠

状态：已实现圆润原创 SVG、32 种表情、独立改色、桌面轻互动，以及 20 级成长、任务、成就、装扮和独立成长存档。养成于 2026-10-26 加入，当前实现与验收见 [养成说明](starpet-growth.md) 和 [验证记录](verification.md)。下文既有改色、互动、重启与安装包替换是对应历史版本的记录，不能直接视为养成版已全部验收。参考许可核对日期：2026-10-24。

## 当前功能

养成第一版提供 20 级、三项日常任务（每天最多 45 XP）、六成就、四槽十件原创装饰，以及问好、击掌、伸懒腰、转圈、比心、庆祝六个主动动作。现有 32 表情继续开放，新增动作不改写其 ID 或已选心情。成长记录默认关闭，独立存入 `starpet_growth_v1`，支持单独导出、预览确认后导入和确认重置；规则及后续未实现项见 [养成说明](starpet-growth.md)。

- 「偏好设置 → 星伴」提供原创星星角色「星芽」：先用 ImageGen 生成 [概念图](starpet-concept.png)，再据图绘制圆润 SVG；[设计说明](starpet-design.md) 保存完整提示词，参考位图只作设计资料、不进入安装包。日常陪伴 8 种、小小心情 12 种、一起做事 12 种，共 32 种状态保持不变。ID、轮廓、表情与动画参数由本项目独立设计，没有复用参考参数表或实现。
- 表情墙可点选预览、按分类筛选，也可开启或暂停巡游。巡游会切换页内主预览，不自动把每个表情应用到桌面。
- 桌面星伴默认关闭。点击「让星芽住在桌面」开启；选中其他表情后可点「用这个表情陪我」。开关、应用表情与颜色独立写入 `starpet_v1`，立即保存，不依赖「保存全部偏好」，不保存其他偏好草稿，也不触发历史清理。
- 配色提供「奶油星光」「蜜桃云朵」「薄荷心事」「薰衣草梦」「晴空来信」5 套预设，也可输入完整 HEX。改色即时保存，并通过事件同步到已开启的桌面浮窗；换心情继续保留颜色。旧版 `starpet_v1` 缺少 `color` 时读取为奶油金 `#FFD66E`，不会仅因补默认值而重写原记录。
- 桌面端配置为默认 230×260、随大小调整的独立透明 Tauri 窗口，本体与顶部把手均可发起原生拖动，另有摸摸、换心情、打开星笺与收起入口。支持手动轻互动，以及单独授权后的本机 Agent 状态、已解锁动作和限时短句；接口见 [AI 与星伴接入](ai-access.md)。星伴自身不联网、不读取剪贴内容，也不分析正文。复用现有技术栈，没有引入大型运行依赖。
- 大小滑杆支持 70%–160%，界面步长 5%；提供轻巧 70%、刚刚好 100%、大颗 140% 快捷档。预览与桌面浮窗实时缩放，连续输入串行合并为最新值；独立写入 `starpet_v1.size`，失败回退到最近确认值。旧配置缺字段默认 100%，读取不重写。窗口按本体尺寸加固定操作空间，放大时尽量保持底部中心并限制在当前屏幕工作区；保存失败会恢复旧窗口大小、位置与可见性。
- 浏览器支持表情预览和内存成长演示，刷新会重置成长，不开启原生桌面浮窗。参考仅限眨眼、注视、呼吸和状态切换等一般表现，没有复制 Grok 角色、第三方素材、眼形坐标、关键帧或受限引擎代码。

## SVG 动作与互动

桌面「和星芽互动」菜单现支持点击外部、失去焦点、Tab 移出和操作其他按钮时收起；Escape 与关闭按钮回焦入口，外部收起不抢焦点。具体行为和验证边界见 [养成说明](starpet-growth.md)、[验证记录](verification.md)。

- 按住本体即可抓起，按下时也会给一次摸摸回应；左键直接发起系统拖动，不等待长按或移动阈值。鼠标 click 不重复触发，键盘 / 辅助激活保留摸摸。拖动没有新增权限，仍只允许移动星伴自己的窗口；位置暂不跨重启保存。

- 基础表情默认以无手的星星轮廓出现，32 种状态中 25 种不显示手；挥手、拿花、放大镜、读书、写字、画画、捧杯 7 种状态显示两颗小圆球。新增主动手势与手持星球装备也按需显示圆球手；读书、捧杯等表情的道具优先，暂时收起冲突的手持装备。

- `src/starpet-behavior.ts` 在动作间安排决策间隔与停顿。日常会观察、探头、平衡和舒展，安静或专注时以观察、点头为主；只有活泼心情会偶尔跳跃，睡眠时不主动选择这些日常动作。
- 星角以 SVG 路径柔性变形，眼神先于脸部和身体转动，各层弹簧带来延迟跟随。指针进入本窗口的星芽区域时会引起注视，离开后保持约一秒，再逐渐收回目光；没有读取窗口外的全局指针位置。
- 眨眼采用不等间隔的单眨和双眨；表情切换带闭眼过渡。偶尔的跳跃仍依次表现蓄力、起跳、落地压扁与回弹；腾空位置沿二维三次贝塞尔曲线运动，缩放按阶段缓动。
- 设置页主预览与桌面星芽都能摸摸。单次轻触会眯眼倾靠，短时间内连续触碰会扭动，专注时点头，睡着时半醒后继续睡。动作衔接保留当前姿态与速度；临时反应不改写已选心情或剪贴历史，启用成长后会另行记录当天问好任务，也不会改变表情墙的 32 种状态与巡游预览。
- 动画循环只在组件已挂载、`animated` 开启、系统未要求减少动态效果且页面可见时运行。停用时取消 `requestAnimationFrame` 并保持静态；减少动态效果下摸摸仍会短暂显示静态笑脸。卸载时清理循环及反馈计时器；图库以静态缩略图为主，没有新增运行依赖。

## 验证与限制

- 2026-10-26 养成版：34 项 Node、前端生产构建、41 项无 desktop Rust 和 43 项 desktop lib 测试通过（Rust 两组各另有一项既有测试忽略）。macOS 隔离 app 已构建并原生核对三任务获得 45 XP、升到 Lv.2 和穿戴眼镜。浏览器还核对了固定成长存档导入、确认期间修订变化阻止覆盖、暂停后动作仍可用且不加经验，以及 70% / 160% 装扮与减少动态效果。完整证据和最终构建以 [验证记录](verification.md) 为准，不能扩大为全平台或长期资源验证。以下各项为养成之前的历史记录。

- 连续行为更新：27 项 Node、31 项 Rust 测试通过（另 1 项既有 CLI 忽略），前端与 app / DMG 构建通过。浏览器验证日常观察、单摸 / 连摸和睡眠半醒；隔离原生实测蓝色星芽眯眼微笑，原心情说明不变，返回主窗仍为 0 历史且暂停，之后退出。正式包已更新启动且数据摘要一致；详见 [本轮记录](verification.md#星芽连续行为与情境回应2026-10-25)。

- 大小更新：24 项 Node、31 项 Rust 无 desktop 测试通过（另 1 项既有 CLI 忽略），前端及 app / DMG 打包通过；隔离原生实测 70% → 140% 即时缩放，正常退出重启仍为 140%，颜色、表情与开启状态保留。测试始终暂停采集且 0 历史；见 [大小设置](starpet-size-settings.jpg)、[70% 浮窗](starpet-size-small.jpg)、[140% 浮窗](starpet-size-large.jpg)。以下既有测试说明对应前轮功能。
